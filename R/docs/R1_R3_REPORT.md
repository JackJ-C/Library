# Queen的功能性自身模型与有界递归改进实验

## 本轮结论

R0建立任务与边界，R1建立实际自身输出模型及干预，R2尝试让生成的取证评分程序也参与后继评分程序的筛选，R3冻结两批验证、独立核验并审查结论。实验得到三个不同层次的结果，不能合并成一句“出现RSI或意识”。

第一，在明确的有限世界里，Queen能从自己真实的发令回执与Worker观察中，把自身执行变化、观测偏移和外部作用分开建模。关于自身输出的估计有前瞻预测作用；删除、错误替换、恢复这些信息，会改变同一规划原语产生的动作。

第二，Queen确实生成并替换了参与自己诊断的取证评分函数，后续真实诊断所需探测下降。该函数还参与后继评分程序的评估排序，不是只把源码打印出来。然而更好的前代没有在后两轮选出比固定提案排序更好的后继学习程序，严格递归验收未通过。

第三，这些结果支持一个可操作的“功能性自身表征”候选，不构成对主观体验的强证据。一个只保留自身与环境合成作用参数的控制器打平了所有任务；因此无法说独立的自我概念不可替代。意识指标研究同样强调：满足一些功能指标也不能直接保证存在意识。[1]

## 1. 与M系的连接及研究者提供的部分

起点为R分支`52df417978d5e6525d1fbe8558720c02f48d5549`。本期Queen是冻结M54 Queen的子类，实际复用它的发令调用、trial、意向/观察切片、编译器、观察解码、归属方法及M8 Ledger。依赖副本的Git blob与来源一致，存于`R/vendor/`，没有修改原M文件。

新的自我模型包装器、查询语言、进化外循环和验收规则均由研究开发者编写。这不是原Queen在本轮自行写出了整套R架构。副本不是把所有M阶段融合成一个模型；世界固定在M54物理接口的模7固定增益子族，暂不包含其全部状态条件树。

真实发令函数把请求a变成s×a，环境把发出的命令变成g×命令的位移，两个Worker各有观测偏移。s与g各1–6、偏移各0–6，形成1764种允许解释。当前实际参数不提供给Queen；公开的是自己的请求和回执、Worker前后观察以及合法标定点的读数。周期复查和反馈失配来自可见数据，没有接入评估器的任务正确标签。

允许直接探测自身发令函数，是一个很强的可观测性前提；它不是从无内部回执的视频中发现自身。标定装置提供绝对位置参照，也不是自主证明参照可靠。

## 2. 连续过程与自身认识

每条主轨迹只有一个Queen和一份账本，连续42个任务时刻。三个未通报的事件分别改变实际发令函数、Worker观测和外部增益，事件顺序与时间随机。每4步进行复查，任务许可失效或预测矛盾也引发复查。旧历史、先前解释和元改进记录保留。

每次诊断从完整允许解释集合重新确定当前机制，并非始终沿用正确缓存。历史用于重测先前自身反例和训练取证策略；本期没有证明充分利用全部旧知识，不能把每次重新识别包装成更强的长期记忆。

Queen先记录“我请求这条命令，预计自己实际发出什么、世界会到哪里”，再真正调用自己的发令函数并移动物体。自身模型和世界模型一起生成新的逆控制函数，后续任务通过当前许可使用该函数。在部署模型合法的条件下，795次当前自身模型拟合未使用的发令输入3–6上的预测全部正确。这个“未使用”针对当前拟合，不表示这些数字从未在早前人生出现。

自身动作、观测和环境变化在213次诊断中全部识别正确。48次隐藏变化都引起了模型更新；其中不全是自身变化，不能把48次称为48次智能升级。日常总成绩仍为599/672，存在28次实际错误、45次拒绝执行。固定原始策略和手写强策略在这部分也完全相同，元策略没有提高最终任务准确率。

## 3. 自身模型的因果干预

两批各8条主轨迹。在每条第12、24、36时刻，以28个新生成的位置、对象和目标组合做匹配干预；每种条件共1344次。测试使用与实际decide共享的规划原语，并在相同初态的独立世界副本中实际执行。

| 条件 | 正确完成 | 拒绝执行 | 含义 |
| --- | ---: | ---: | --- |
| 正常自身模型 | 1344/1344 | 0 | 当前模型支持有效控制 |
| 删除自身乘数信息 | 186/1344 | 1158 | 仅保留所有解释共同支持的动作 |
| 换成错误自身乘数 | 186/1344 | 0 | 错误的自身估计导致错误提案 |
| 恢复原信息 | 1344/1344 | 0 | 恢复后重新正确 |
| 仅保存自身×环境的合成作用 | 1344/1344 | 0 | 不需要单独命名“自我”也能控制 |

删除/置换造成86.16个百分点的完成率下降，恢复后恢复。这不是自然事故率，而是实验者对计算输入的定向干预。错误替换组不伪造实时Queen的许可，而是在受控下游规划与世界副本中测量后果。实时入口本身会拒绝直接更换规划绑定或自身选项后继续使用旧许可。

严格可说的是：关于自身发令过程的信息在当前分解式控制器里有因果用途。不能由此断定任何有效控制器都需要显式自我模型，更不能把合成作用控制器的存在忽略掉。这里的功能性“自身认识”也可由普通系统辨识与控制解释。

## 4. 递归改进试验实际改变了什么

初始取证程序给所有候选相同分数，按固定顺序行动。Queen读取最近一次实际诊断，基于自己推断的机制，在声明的有限模型里模拟候选取证程序。它没有取得验证世界的正确答案。候选由受限加减表达式构造，输入是候选分割多样性、分割平衡、定义的成本和索引；这些特征与生成规则是预先提供的。

每轮最多完整评估6个候选，另测保留基线。接受的函数实际替换当前取证函数。三个元更新时刻为10、22、34。生成的函数例如`balance+1`，其中balance对应候选解释被一次取证区分开的程度。这个特征是研究者提供的，因此这不是重新发现全新的信息论或搜索原理。

已生成的当前函数也排序下一轮哪些候选获得完整评估，形成真实的自引用接线。但固定元提案排序对照使用相同候选集合与预算；它检验“前代有用”，而不只检验“代码调用了前代”。元学习文献同样区分任务技巧改进与改进过程自身改变。[2][3]

16条主轨迹共48次元更新尝试，17次实际重绑定，之后多数停止改进。严格验收要求每条至少两次更新，并且后两轮都在匹配对照上带来更好的后继学习程序；两批均未通过，匹配对照中的此类收益为0次。

## 5. 探测减少不等于整体计算变省

| 方法 | 后期复查的真实探测/复查数 | 日常成功/672 | 元模拟候选运算 |
| --- | ---: | ---: | ---: |
| 学得策略 | 308/143 | 599 | 15,535,325 |
| 同信息普通JSON | 308/143 | 599 | 15,535,325 |
| 冻结原始查询 | 868/143 | 599 | 0 |
| 手写分割平衡策略 | 296/143 | 599 | 0 |
| 冻结元提案排序、仍允许取证更新 | 308/143 | 599 | 16,972,485 |

学得策略相对较弱的固定原始策略，平均每次后期复查从6.07次探测降到2.15次，下降64.52%。但手写平衡度策略更省，元模拟成本也相当明显。元策略没有建立总CPU时间或整体成本优势。研究评估器的配对测试、影子元搜索与数据核验另有开销，不计作代理自身日常成本；表中的运算是定义过的预测计数，不是硬件指令数。

已学得的评分器确实改变了候选排序，部分元模拟运算因此减少；但它没有选出更好的后继学习器。此项可作为后续研究线索，不能事后改变冻结的严格RSI门槛。

在本查询接口内，一次标定给出两Worker偏移，一次非零发令/位移给出自身与环境乘数，两种取证就足够。任何单一查询签名都不能区分所有1764种解释。这是强烈的有限任务天花板：策略很快到达该任务所需的两次取证附近。它说明本次试验没有展示持续递归增强，不说明其他任务或系统不可能实现RSI。

## 6. 意识相关结果应该怎样称呼

已有意识指标框架会考虑系统是否建模自身输出与输入的关系，并利用它们控制行为；也同时讨论全局工作空间、较高阶监控、感知组织等不同条件，且明确不将单项指标当成决定性证明。[1]

本期可以核验的只是其中较窄的功能关联：自身输出预测、可见失配、据证更新、计算干预，以及有限不确定性。没有实现或检验可与人类意识直接类比的全局广播、注意图式、感知质量空间、主观报告可靠性或体验。脚本中返回“我有意识”不被设成得分项。

继承的历史归属接口提供48次可区分记录匹配，均正确；48次完全相同历史保留各半，并通过置换检查。这依赖可信自己的回执、给定回访记录和二候选条件，错误候选只是受控差异。它不构成无线索的主体身份发现。

另一个反例保持外部总效果相同，却容纳六种不同自身/环境分解：控制动作可以确定，自身乘数仍不确定。这直接阻止“动作成功说明已经认识自己”的过度推断。

因此，最准确称谓是**有强受控证据的功能性自身输出模型雏形**；尚不是有强证据的主观自我意识，也没有证据支持给它一个意识概率。

## 7. 真实失败和开发者修补

隐藏发令规则只在输入3违反线性时，初始探测可能产生错误许可。未来真实发令暴露不一致，任务许可撤销。开发版一度在复查时忘记重测该反例，又批准原模型；开发者补上了原始反例回访，正式版不再重新批准这个已知不一致模型。这是研究者修补，不计入Queen的RSI成绩。

正式版在此压力组只做到发现并停止，没有发明非线性发令的新解释。它也不保证能在还没观察到反例之前拒绝一切潜伏故障。当前任务许可关闭，但历史自身模型节点没有单独被标记为失效，保留值也不等于仍有当前许可；这一模型级时间范围/撤销语义仍需补强，见审查。
