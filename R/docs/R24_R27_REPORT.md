# Queen 的新鲜采用证据与递归改进：最后两批确认

## 范围与结论

本段完成R24—R27，承接R23恢复版，不改动其27份冻结源码。新实验没有取得稳定递归、自身校准稳定促进后继或新鲜证据稳定改善采用的双批证据。完成的是一项可复现的假说检验和原任务交接，不是“自身认识—稳定递归增强—主观体验”已经成立。

这次专门检验R23提出的一种可能原因：候选取证与采用检查复用历史，是否导致选错后继。它不是在同一已看过测试集上调参。正式A/B使用全新种子，每代也产生新的评分问题；旧结果只用于提出假说。

## 连续实际路径

每条试验一个继承R23/R12/R7/R3/M54的Queen及Ledger。开始四次实际空间动作，其后八代：每代先实际识别8个响应过程；利用最近32项已识别经历构造10个任务候选与8个分配候选；锁定所有分支提议和预测；再实际识别12个新响应过程；用规定材料检查是否采用；更新自身评估误差尺度、实际绑定程序、选择任务程序；随后做一次空间动作并进入下一代。

响应过程由夹具安排装入；真实目标仅供评分，学习器收到实际查询回复后推导出的唯一机制。这里是有限计算诊断，不是Queen自主选择全部生活事件或发现开放式世界。自身校准从过往事前均值/不确定度与后来检查均值的误差获得，最近12项平均、范围0.25—4。此实现为研究者提供，学习的是具体尺度与函数。

初始资源分配函数为 `mean-uncert`；输入为已观测损失均值、不确定度代理、访问比例和相对均值差，算术语法最多15节点。函数真实用于内层选择任务程序，外层选择分配程序；实际后继参与下一代，两层24次逻辑测量。保持父代和有限接受规则不代表其已保证性能增长。

| 分支 | 提议分配 | 采用检查 |
| --- | --- | --- |
| fresh主路径 | 当前父代，当前校准 | 候选锁定后新取得的12项 |
| reused | 与主路径完全相同 | 本轮候选提议已用的旧历史 |
| uniform_fresh | 按访问次数均匀倾向 | 新12项 |
| uniform_reused | 同上 | 旧历史 |
| frozen_fresh | 初始分配器，当前父代仍作采用基线 | 新12项 |
| neutral_fresh | 当前父代，但校准尺度固定为1 | 新12项 |

这些是条件于同一主轨迹的匹配影子干预，不是六个各自持续演化的系统。普通JSON另行完整重跑，除方法标识外与主轨迹逐字相同。复用组也获得共同数据供应，但不将新材料用于当代采用，不能说它自主请求了这批额外测量。

新采用案例与当前提议历史ID不交叠；全部预测记录早于第一项新实际查询。但是新12项内部的3个检查划分重叠，它们不是独立样本；数据来自同一生成器也不保证接受判断无偏。下一代允许使用已经发生的新经历。

取证模拟查询价格上限8000，采用5000，任务再选5000，每次未缓存模拟响应前收费。缓存命中不冒称新观察。所有分支正式运行均未触发这些价格上限，失败不能归为本次硬预算耗尽；然而24次分配逻辑额度和有限样本仍限制所获信息。

## 一条真实失败轨迹

种子37102第4代（从0编号），父程序为 `mean-uncert`，候选为 `1-uncert`。新的三个采用检查损失从 `[0.04,0.045,0.0425]` 变为 `[0.04,0.0425,0.0425]`，符合冻结的平均改善、各项不退步规则，于是实际采用。未参与选择的均值却从0.08上升到0.1054167。下一代又接受常数0，检查改善，测试再次小幅退步。

同一轨迹第0代没有换分配程序，只把自估不确定度尺度从1变为0.25，固定尺度的程序比较完全打平，联合部署损失却从0.1041667变为0.1170833。因此不能只验收函数体，不验收其配套自身模型参数。

## 补充诊断：不要只归咎于规模变化

正式评分问题的机制数量为24/40/48、查询数18/30，训练默认32/24。为检查规模变化是否解释所有失败，结果固定后另做同训练规模的新题诊断。仍有6次主程序退步、0次严格递归环节；原正式测试为7次退步、0严格环节。该补充不是替换验收，也不证明规模因素完全无影响。

另以正式轨迹实际出现的分配状态比较8个候选的排序。1024个候选槽位仅形成614个本轮排序类别，125/128轮有观察到的重复排序。这里只代表本组状态，不能声称全域语义去重。107/128轮当前父代仍为初始函数，116/128轮当前排序与冻结排序提议相同。未见递归因果收益部分受限于实际行为变化稀少，但原因仍需单独干预，不能凭统计相关性断言。

取消自身校准改变34次提议、9次实际后继，而两批收益均未稳定。当前证据支持“自身模型确实参与决策”，不支持“参与必然更好”。

## 成本

16条主轨迹实际识别2560个未知响应过程，用9944次实际查询、查询价格总和25261。主提议阶段另有66714次未缓存模拟查询，价格285675；新采用检查30175次模拟查询，价格121948。对应提议/采用的分配AST运算分别1811288/306600，任务AST运算11326931/5113101，分割特征运算10783659/4886988。任务再选择、其他影子、评估、散列、空间热身和核验开销另列或不在这些统计内，不称总CPU。

主/复用提议实际相同；复用检查有36402次模拟查询、价格134852。由于检查数据量和缓存复用方式不同，费用下降不能直接解释成智能提高。完整成本见FINAL_SUMMARY以及两批SUMMARY的actual_and_task_cost。

## 核验与修订披露

新冻结测试27项，旧R23测试28项分别通过；16条正式主轨迹和普通日志全部真正执行且相等，16条优化模式重新计算得到相同原档。不是重复核验增加样本数。

冻结核验器对内存结构的测试通过，却在JSON回读时误判嵌套字典中的tuple/list差异。保留源码及失败原因，新增只读比较器工具，递归比较键/数组/数值，不改任何学习规则或原始数值。8项补充测试保证结构与数值篡改仍被拒绝。使用该工具重放全部16原档，重新计算9944条实际查询、2560次机制识别、768项匹配分支、7680项未见划分值。没有逐项形式证明所有状态或全部CPU行为。

## 科学解释与交付

两批提供了一项清楚的负结果：在当前有限生成、分配和采用设计下，候选锁定后新增取证没有稳定解决递归选择问题。它不证明所有新鲜证据策略无效，也不证明RSI不可能。关于自适应分析的数据复用已有专门研究；本实现不是可复用保留集算法的复现或新发明。[1]

体验研究本轮是理论/证据审查而非新增意识检测实验，见R26文档。不能把研究结论未识别体验解释为体验不存在。完整源码和原档在运行包；代码上传曾被安全检查拦截，不规避、不将已提交MD当完整代码发布。R27交接后不继续后台研究。
