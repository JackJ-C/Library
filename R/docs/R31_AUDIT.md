## 旧核验器能被什么骗过

在43100_space的一份内存深复制上，分别改动以下内容。**旧核验器接受了9种篡改副本，新增核验器全部拒绝；原压缩原档摘要前后不变。** 另有一个未修改JSON回读正控制，合计10项测试通过。

| 篡改对象 | 旧检查缺口 | 新增检查 |
|---|---|---|
| summary更新次数 | 未重算全部汇总 | 从每代实际采用推导 |
| evaluation均值 | 重放块值但未全面连接均值 | 由所有块重算均值 |
| shortlist索引 | 未完整核验提议排序 | 从pilot与距离重新排列 |
| 采用old/new列表 | 局部门槛检查未绑定原响应 | 对应到实际四块干预结果 |
| 模拟AST运算数 | 只覆盖部分真实query计数 | 重算三类引擎的调用与缓存成本 |
| 几何维数字段 | 未全面核查元数据 | 重建保留坐标及分类 |
| 绑定的scale | 未连接所有部署字段 | 受检组合与实际绑定相等 |
| UNKNOWN改成PASS | 未全面检查证书声明 | 重算并保持UNKNOWN |
| previous_adopted标志 | 依赖所存布尔量 | 按上一代实际采用重算 |

这说明旧核验器“通过”并不独立支持所有报告字段，但**不意味着原48份结果错误**：它们在更强的补验下保持原值、继续通过。没有把新增核验器放进旧FROZEN或更改历史版本来制造“原先就完整”的印象。

## 科学与实现边界

1. 本期继承R3/M54/M8和R23/R4的Git可得代码。缺失的R24—R27完整实现不在本包，不能冒称复现了它。
2. 点为allocator AST与scale，任务候选和历史在匹配比较中固定；没有认证R28理论中的全部持久状态。任务程序实际重选也不等于已对其未来分布做保证。
3. 空间是按当代见证形成的局部响应伪度量，非连续因果流形，非跨代统一坐标。坐标生成规则和距离由研究者提供。
4. 源码构造了完整响应记录，但几何签名只选用了后续诊断路径；不保证代表全部内部计算后果。
5. 几何重建对照在同信息同计算意义下等价，结果打平必须保留，不能宣称“图必然不如空间”。
6. 每批8个配对种子轨迹是统计单位，48条路线、288代和查询数量不能冒充独立重复。bootstrap区间仅小样本描述性判断。
7. 实际采用在有限新银行上经验改善，保守分布证书UNKNOWN；没有事后升级证书，也没有无退步保证。
8. 只读补验仍依赖同一个问题生成器、PRNG与已声明的解释器语义；不是独立团队、真实物理引擎、整个进程的形式证明或任意恶意篡改安全隔离。
9. 补验没有独立重放全部旧空间世界动作，也没有将几何构建、散列、读取、缓存内存及CPU总成本统一计费。函数/scale绑定和实际任务连续执行另由冻结单元测试及记录提供证据。
10. 最高层度量规则、程序语法和验收器不是Queen自创；当前功能证据不等于主观体验。
