## 2. Queen这次构造的“空间”究竟是什么

固定任务候选集合、已由真实opaque查询识别的有限机制、内层测量协议后，一个点为：

\[
 b=(a,c),
\]

即一个有界allocator程序与其不确定度尺度。对每个点实施实际程序替换，在有限模拟器中运行任务选择及后续诊断。观察到的响应包括诊断轨迹、代价、被选任务和内部分配请求。这里的“实际”是确实执行了相应代码和opaque响应查询，不是实体机器人或自然世界实验。

在用来组织几何的响应签名中，第j个坐标是该干预在第j个已知机制块的两条后续诊断轨迹：

\[
 \phi_t(b)=(s_1(b),\ldots,s_{k_t}(b)),\qquad
 d_t(b,b')=\frac1{k_t}\sum_{j=1}^{k_t}\mathbf1[s_j(b)\ne s_j(b')].
\]

每当新增响应列可以拆分已有等价类，Queen保留该列作见证坐标；第一列即使常数也被保留，以记录非空作用范围。它形成候选点上的伪度量，在当前观察等价类的商集上形成度量。`dimension`字段仅为**保留坐标数**，不是智能维数、内在维数或连续流形维数。

坐标和版本都依赖真实取证记录；支持撤回可以撤销相应许可。原始历史引用不因此删除。图重建对照从同一账本中读取响应列，重建距离而不是直接读取缓存。

有四个不能省略的限定：

1. 这是**有限元程序干预响应空间**，不是整个世界或Queen全部状态的因果空间；本期点只显式覆盖allocator与scale，不是R28理论中的全部Theta=(p,a,c,m,eta)。
2. 各代重新根据当前候选和历史构造局部空间，旧版本入账；没有实现一个跨代对齐、连续生长的全局坐标系统。
3. 坐标选取规则、Hamming距离、语法、生成器和验收器由研究者提供。Queen生成具体见证、分类和运行中的程序，不等于创造这些最高层规则。
4. 几何只使用部分后续响应签名。它不完整编码所有内部计算路径、未来情境或收益方向；当前同类不能被永久合并为同一个程序。

因此用户提出的“从图演化到空间”，本期落地为**从可追溯干预记录构造可撤销的局部效果几何，并让它改变候选筛选**，而不是把因果图绘制成三维画面，也不是证明空间在信息上超越图。

## 3. 固定实验与对照

正式A=43100—43107，B=44100—44107；开发种子仍仅0、1。每个种子分别运行space、raw、frozen三条持续路线，每条6代，共48条路线、288代；统计独立重复以每批8个配对种子为单位，不能把三条路线或每个查询当作独立重复。

每代8个allocator/scale候选、6个任务候选；内层12次逻辑测量，pilot最多3块，最多进一步完整检查2个额外候选。提议和配置先冻结，随后取得4块真实新采用经历。采用后才生成6块评估器专用测试问题；测试结果不回流给Queen。后继allocator真正选择并绑定后续任务程序，同一Queen和Ledger持续存在。

| 对照 | 被改变的内容 |
|---|---|
| space持续路线 | 使用局部等价类去冗余及距离新颖性项筛选候选 |
| raw持续路线 | 同样pilot信息，不使用距离与去冗余 |
| frozen持续路线 | 提议者始终为初始改进器；其Queen仍能采用后继、形成自己的持续历史 |
| graph匹配影子 | 从相同账本无损重建几何；信息与算法等价的强对照 |
| shuffled匹配影子 | 故意错置干预点与响应的归属，不是合法坐标改名 |
| collapsed匹配影子 | 距离与类别信息退化为零 |
| previous／initial影子 | 其他条件匹配，替换为前代／初始提议者 |

几何效应、局部递归因果效应、持续路线效果分别统计。每批95%区间使用事前固定5000次种子轨迹bootstrap；它是小样本描述性区间，不是分布无关有限样本定理。

本期采用门槛是在新有限银行上平均改善>0.002，允许离线探索性替换。保守总体风险证书全部仍为UNKNOWN。**这不是R28认证部署定理的成功实现，更不具有未来绝不退步保证。** 同一AST与scale受检并部署，并不意味着整个持久状态、任务程序和世界分布均已被认证。

## 6. 两条具体反例轨迹

**43101，第3代（从0编号）。** 上一代已经采用了`visits-uncert, scale=2`；本代再采用常数`1, scale=0.5`。相对当前父代，测试改善0.002314815，看似形成两次连续更新。但前代／初始提议者产生的对照后继比实际后继好0.027777778，因此gamma_previous与gamma_initial均为负。**连续更新、连续局部改善都不足以证明递归增强。**

**44101，第2代。** 采用银行改善0.003472222，通过了0.002门槛，实际采用常数`-1, scale=2`。未见测试却退步0.002893519。程序和scale一起检查，仍可能因有限取证而误采用；空间表示没有自动解决统计选择问题。

## 7. 结果固定后的瓶颈诊断

正式决定全部结束后，使用每轮已有的评估器测试银行，对当时8个候选做完整离线评估。**此项事后诊断不在原确认门槛中；最佳候选是事后上界参照，不是Queen能够事先取得的答案。** 没有增加正式种子或将评分结果回送学习器。

| 96轮主space轨迹的筛选环节 | 次数 |
|---|---:|
| 候选池存在测试表现更好的候选 | 54 |
| 实际提议测试更好的候选 | 13 |
| 提议正确方向但随后拒绝 | 7 |
| 采用后测试改善 | 6 |

| 采用后测试打平 | 2 |

这排除了“所有轮次根本没有任何好候选”作为完整解释，但并不证明有限证据下总能识别那54轮的好候选。它把候选供给、提议辨认和采用噪声拆开了。

另一个直接结果：pilot阶段共有1339对当前同类候选，其中650对在已有未见银行上产生不同响应；96轮中81轮出现这样的局部分裂。平均pilot类别2.604167，完整测试响应类别3.645833。这些候选对高度相关，不是1339个独立自然样本，也不是总体错误率估计。

它提供了具体反例：

\[
 d_{\mathrm{pilot}}(b,b')=0\quad\not\Rightarrow\quad
 s_{\mathrm{new}}(b)=s_{\mathrm{new}}(b').
\]

几何可以正确描述已有见证，却仍不能可靠区分新情境。当前实现没有永久删除候选，所以不构成执行违约；但本代去冗余可能错过后来有区别的选择，需要未来单独干预检验，不能把事后相关性当成已证明的失败原因。

## 8. 本期推进点与没有推进到的地方

本期真正推进了三点：

- 因果空间从概念变成持续Queen上的可运行、可撤销、可干预的局部响应结构，并确实改变了候选提议。
- 原先“代码形式重复”的问题变成可测量的当前响应等价类；同时发现了大量仅局部成立的等价，不能靠一次去重解决。
- 用前代／初始提议者和真正持续对照，区分了普通适应与递归因果改进，并将当前失败定位到提议／采用的辨认环节。

没有建立的主张包括：空间胜过相同信息的图或日志、稳定有限RSI、开放式RSI、完整状态的分布认证、全球坐标体系自主生长、元原语和最高层规则自主创造，以及主观体验。

最有信息量的后续问题不是“把维数增大”，而是：**能否从带来源、上下文和成本的干预响应中，形成可被推翻的收益方向预测，并在相同取证预算下胜过只按距离探索？**

距离只回答“行为不同吗”，不回答“往哪里改会更好”。一个后续候选是把上下文条件、干预序列、响应与代价联合建模，给旧局部等价保留不确定度，并主动寻找能区分收益方向的见证。本报告没有运行或登记这个后续方案，尤其不把研究者写下它算成Queen自创，也不预占R32。
