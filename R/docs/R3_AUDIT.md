# R3证据与接线审查

## 已核验

R内副本与六个M来源文件的blob/SHA256对应。实际Queen继承M54类，调用原trial、Worker解码、意向/观察记录、编译器和M8账本。原M目录没有修改；本期不是把新玩具命名为Queen后冒称整个M架构自动拥有新功能。

实际自身估计参与与decide共享的动作规划，未来绑定受到许可检查。直接更换规划函数或自身选项会关闭执行；删除/置换/恢复的数值实验是下游计算干预，不伪造主任务许可。配对世界状态相同，结果不回流到学习。

真实取证函数由受限算术源码产生并绑定，下一轮的候选评估排序也调用该函数。固定元排序对照保持候选集与完整评估预算相同。接线存在，但没有更好的后继学习结果，不能用调用图代替RSI因果收益。

两个Worker标定读数都进入推断，没有把已取得的第二读数藏掉制造额外探测。评估器的参数与成功标签不进入推断函数。诊断失败不被计为正确任务，在线28次错误和45次拒绝保留。

## 尚不能作强解释的部分

**A01：严格RSI未通过。** 48次元更新尝试只有17次实际改变，后两轮的匹配后继学习收益为0。这个简单可识别任务很快到达两次取证下界，需要更有学习余地的新问题才能研究持续递归增长。冻结生成语法、特征和元评价并不在逻辑上排除所有RSI，但它们限制了本轮证据。

**A02：意识证据不足。** 自身模型属于对真实发令函数的系统辨识。合成作用模型完全打平；工作空间、注意图式、感知质量和主观体验未验证。不能把“自我”字样、类名、函数ID或任务成功当意识指标。历史归属只是继承的带可信回执匹配题，不是新的自发身份发现。

**A03：非线性自身规则未修复。** 已知反例重测能阻止重新批准，但无法构造族外规则。模型级撤销还有语义缺口：任务许可被撤销，而旧R_own_model节点没有独立失效标记；读取旧模型内容不代表它仍有当前作用范围。R4应先将“历史可读”与“当前有效”在自身模型接口上分离，再扩展研究。

**A04：有限探测与来源假设。** 允许直接调用内部发令函数的无副作用诊断，可信保管回执，并由已知位置标定。外部控制者、受污染内省接口、状态化发令程序或共同传感漂移可能超出模型。不会因一组参数全部识别就推断这些问题已解决。

**A05：研究者提供而非自主长出。** R包装器、假设族、候选算术语言、平衡度特征、模拟器和验收均手写。Queen生成的是具体评分函数和逆作用程序，并没有创造这些整个架构。开发者对旧反例回访的修补不计为系统自身修补。

**A06：成本。** 报告候选预测计数、真实探测请求、诊断发令和标定标量，并另算元模拟。该计数不是全CPU；世界副本、影子元搜索、程序编译和核验也有开销。以探测下降64.52%声称总效率上升同样幅度将是错误的。

**A07：数据与复现。** 正式原始输出全部上传的含义是两个run产物被无损保存；只有每批首主轨迹附完整Ledger，其他轨迹是详细行为/干预/元搜索记录。独立核验器是不同代码路径，不是独立实验团队，也不是对全部证据来源的安全认证。初始双批串行调用曾超时中断B，B在未改代码下完整重启；没有把中断当研究失败或删掉已完成的A。

**A08：范围。** 没有对M全库重跑，没有修改其他分支，没有运行自主后台代理，没有自由生成文件读写或网络代码。学习到的表达式运行在明确的算术语言内。R运行副本下的M文件来自既有授权仓库，不导入其他GitHub项目。
