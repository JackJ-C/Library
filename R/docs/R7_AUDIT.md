# R7：证据、接线与下一步边界

## 已实际核验

1. 新子类沿用旧R3/M54 Queen和M8 Ledger，R目录内的旧冻结文件摘要保持一致。R5诊断、R6学习与主方案任务发生在同一个对象和账本中。新的计算诊断过程、近似规划器与监控脚手架由开发者提供，不能归功于Queen自发创造架构。
2. 旧自身认识失效后，直接当前查询不再返回旧值；历史仍可读。改的是同一个callable的内部规则，因此不是靠函数名或地址辨认故障。外部失配不能凭空证明自身输出模型错误。
3. 已生成的排序器真正选择后继候选，实际后继函数进入下一代诊断。匹配对照共享父程序、候选、训练数据与6个评价额度，不拿调用图冒充收益。全期的递归门槛未通过，局部8105轨迹及其最后退步均保留。
4. 可靠性表由自身原始意向与Worker后果重建，不直接接受评估器correct。原始快判断相同，改变可靠性表会改变复查分配和实际后果；恢复/改名对照证明作用是数值映射，不是名字。
5. 撤回监控支持后，当前可靠性查询未知；未被撤回的发令和校准模型仍可用。普通日志保持相同数据和程序时打平。
6. A/B的16份源码与合同摘要先冻结。两批分别执行、不互调参。32项新测试及24项旧R3测试实际执行；普通/-O用不同检查点目录重跑，相同原档。独立核验器没有导入学习器来给学习器自证。

## 不应跳过的限定与未验证项

**A01｜稳定RSI没有建立。** 16条只有1条出现相邻两代严格因果收益，两批配对区间跨零；54次实际更新不能充当持续改进。有限采用检验可导致未见代价回退。候选描述、表达语言、目标与接受器固定；原来的空间条件模型没有被R5自动重写成这个新签名问题。

**A02｜二阶功能不是主观体验。** 可靠性表是八个格子的Beta计数与固定分箱。该方法能够充分解释结果，无需额外假定主观体验。它不是完整高阶感知理论、全局广播、注意图式或质量空间的实现。实验不测“我有意识”的文本报告。

**A03｜“属于Queen自身”的范围。** 被监控的是在该Queen上执行的近似规划器；自身数据来自它真实发令后的结果，不是Worker或评估器提供的可靠性标签。不同计算流的表更差，但donor是同一物理模型上的另一种近似计算，不是第二个完整自主主体。旧归属仍依赖可信回执和给定线索，未增强成无线索身份发现。

**A04｜监控调度是批量而非严格在线。** 为使复查数完全匹配，各方案可以读取本批128个内部竞争痕迹，选32个复查，不能看到未来物理成败。未来批次不参与拟合，但这是批量排序实验，不证明在线局部阈值同样获益。两批仅8个独立主种子，不能将嵌套任务数当大样本。

**A05｜近似规划器与强检验器均由研究者预置。** 复查会调用已学准的精确规划器；始终复查可得全对，但代价四倍。监控并未产生新正确答案，只把有限检查分配得更好。噪声、特征、训练量、校准可靠性和精确物理子族都是实验设计前提。

**A06｜监控的版本适用性仍有缺口。** current_reliability检查监控节点依赖和模型对象绑定，但没有独立核查被监控近似规划器的全部内部参数或分布是否变了。其噪声过程/内部习惯改变后，旧可靠性估计可能在新反例前过时；本期测试未声称解决这种漂移。下一期应先研究来自Queen自身的分布/能力变化而非继续堆静态准确率。

**A07｜依赖完备性不是形式证明。** 重建监控读取事前意向与事后观察，但最终模型经own_error_check主要依赖观察和校准；原始意向撤回的传播没有单独覆盖。R4修补自身模型时效不代表所有元监控的依赖都已完备。需要下一期用语义支持逐类撤回检查。账本是同进程API约定，任意越权写列表仍可能破坏记录。

**A08｜任务入口范围。** 普通规划入口有许可检查；研究用近似规划behavior_receipt直接执行拟选动作以收集经验，没有把这些故意不可靠动作伪装成全部已被旧精确模型批准。报告中的“执行许可”不等于一个覆盖研究驱动所有动作的安全沙箱。未测试安装中断、并发、进程崩溃恢复或恶意候选。

**A09｜二者同处一对象，不等于互相增强。** R5的搜索结果不用于创造R6的监控结构，R6的可靠性估计也未反馈给R5候选接受。联合连接是真实状态延续，不是已经形成完整反思—递归增强耦合。这样的耦合要另立可反驳的实验。

**A10｜成本与资料覆盖。** 报告真实查询、带权查询、模拟查询、表达式/分割运算及复查额度；并非全CPU/内存统计。每批仅第一条主轨迹存全Ledger，其他轨迹记录候选、行为和干预；这不是缺失输出被称完整中间状态。单次工具时限后采用同冻结函数、分轨迹检查点；未通过缓存复用假称优化模式重新执行。

**A11｜原创性。** 有限程序进化、信息分割/代价启发式、置信度校准及高阶元学习均有先例。本轮贡献在于一条精确可重放的归因/干预组合与负结果，不是全球原创搜索原理。

## R8建议的唯一下一步

先完善元监控的语义支持与适用范围：撤回自身意向、改变实际近似规划过程或使其能力随经历变化时，当前可靠性判断必须有条件地失效/重学，而不是套用固定分箱。保持同一对象，用前瞻复查决策检验它能否发现“我判断的可靠性已经变了”。R8尚未实施，不将本建议计为完成。
