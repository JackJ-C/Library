## 当前进展：M0–M28 / v0.7

唯一实验仓库为 `JackJ-C/Library`。不连接主系统、不操作其他仓库、不启用付费计算或后台代理。旧 M0–M24 的合同、代码、报告和原始结果保留，PR #1 不改动。

**本轮生成了两个高阶造工具函数体和一个数值反馈搜索函数体。** 它们不是从完整规则表中选择，也不只是改变搜索分支的顺序。生成规则经过独立代数核验，冻结后在256个组合迁移任务上实际运行。

这仍有明确的基础：性质目标、锚点、基本算术、外层枚举器和安装器由研究者提供。搜索公式与经典割线公式等价，强手写基线打平。当前是可核验的项目内推进，不是全球新数学或无条件无限自我创造。

## 一个实际产物

第一构造器由程序搜索得到：`C0(f)(x)=f(x)-f(0)`。

第二构造器调用第一项已生成程序，再得到：`C1(f)(x)=C0(f)(x)-x*C0(f)(1)`。

搜索函数根据两个参数和两个残差计算新参数：`(p1*r0-p0*r1)/(r0-r1)`。它不是任务答案查表，但属于已知的割线/逆线性插值方法。主程序和独立树解释器都实际执行了生成表达式。

元规则的性质有条件恒等式支持；最终任务是否属于其可解决的结构族，是另一个假设。不能把前者的全域保证借给未观察的新目标。

## 成本和强对照

在相同256任务上，生成搜索律、顺序枚举、二分分别使用761、8708、1802次候选程序试算。强手写插值与生成方法同为761次，JSON历史同信息下也打平。

**它们都取得相同1536个外部目标观测点。** 候选试算减少不等于观测减少或墙钟加速；元学习还付出了16984次候选尝试。所有失败、拒绝和学习成本分别记录。
