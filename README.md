## 已经运行的受限实验

在公开函数结构、隐藏实际参数的 256 个二值传递世界中，系统都用 4 次诊断探测找到了正确的内部端到端校正。192 个采用新校正，64 个不改；中性受控环境中，部署后的正确任务数为 2048/2048，修改前为 1280/2048。

同信息、同算法的普通完整日志在全部世界完全打平。因此没有证实特殊存储或递归记录本身的独立优势。四次探测只计诊断，不含另外十六次旧/新验证调用及八次部署后审计；不是计算或内存最优性。

完整识别各部件需要八次探测；只确定修复时仍有十六个兼容世界。双 Worker 共享部件、保留各自来源的 1024 个组合，完整识别需要十次，分别重查为十六次。

在声明 Worker 改变的 768 个事件中，保留兼容历史把重新诊断从四次降到两次；另 768 个环境改变事件不改变预定内部修复目标，因此不必重查该目标。变化范围是可信输入，不是系统自主猜出的。

模型族外的非线性故障使诊断器自信提出错误方案；现有较广的采用门禁拒绝了全部 256 个方案。这不代表学会了新机制，也不代表通过了补充协议中独立于采用的最终挑战。

## 边界与原创性

仅在 `JackJ-C/Library` 研究和提交，不访问其他仓库，不接入希珀塞莱妮娅主系统，不调用付费算力或 GitHub Actions。

Worker 的历史不因被 Queen 读取而成为 Queen 的亲历。空间切片暂指可访问的关系，不要求三维房间；数据库或序列也能保存同样关系。现有证据支持的是受控有限自修正，不是记忆容量带来的自动进化。

与决策区域识别、自建模和自修改研究已有明确交集，不能换名当首创。候选贡献及尚未验证的部分见 [原创性核对](docs/NOVELTY_v0.2.md)。
