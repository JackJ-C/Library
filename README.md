# Library：希珀塞莱妮娅的图书馆研究

> 让系统重新访问过去的行动与判断，检验证据现在还支持什么改变；也检验负责审查的程序自身是否可靠。

## 当前进展：M0–M20

本仓库延续“图书馆／切片观察自己”的原始问题。中文记录、原始证据和阶段编号保留；不预设Transformer或三维存储。唯一实验仓库为`JackJ-C/Library`，不连接主系统、不操作其他仓库或付费服务。

**当前为v0.5研究版，不是最终三个强目标已全部完成。** 本轮直接测试审查、生成、验证、读取、任务和调度函数受损后的交叉恢复，并生成固定候选表外的新任务程序。外层采样/收票/安装和任务参照仍可信；未知分支与共同故障仍可导致失败。全球原创性未建立，已有直接相邻工作。

## 本轮结果怎样读？

四个逻辑审查单元中任意一个均可受损，包括它自己的审查和合成函数。按已冻结的两种错误方式和全部六槽非空组合，504次均由同伴证据恢复。复制的是同伴已有正确函数，不是新审查算法创造。四个单元全部损坏时仍无法恢复。

程序生成从递归表达式语法搜索，不再只选12个完整候选。24任务含1个数学重复，每个56项未见检查通过；主族均首轮成功，没有实际触发反例后的多轮重合成。语法、参考反馈和资源边界仍固定，不能称为任意未知机制修复。普通JSON日志同信息下仍打平。
