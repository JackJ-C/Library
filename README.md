## 当前进展：M0–M11

已完成一版有明确适用范围、条件证明和可运行核验的有限理论：**Library v0.3——可撤销证据驱动的再观察**。

当前 Queen 可以重新读取保存的旧解释，依据反例扩大符号模型，撤销失去假设支持的旧判断，再在明确范围内重新检验修改。尚未实现任意程序自修改、自动发明新观测变量或无限自主进化；全球学术首创和现实任务优势也未建立。

本仓库保留《星际穿越》图书馆与“德罗斯特”表达中的核心直觉：切片可以被后来重新进入，Queen 可以检查自己以前怎样理解 Worker 和整个系统。它不预设 Transformer、语言模型或真实三维存储。

## 一个不能省略的区别

**收集新证据与扩大解释模型，不是同一种进步。** 固定模型内的一致证据可能增加共同允许的修改；扩大模型后，旧证据从未排除的新解释可能重新出现，旧修改许可反而消失。

因此，过去被批准的判断应能被现在撤销。但“撤销旧判断”不能顺手撤销“指出旧判断错误”的正确复查：历史引用不是证明依赖。

同信息、同推理的普通日志依然可以做到这些。本轮没有证明图书馆的存储外形、三维空间或递归深度本身更智能。

## 复现

本轮独立入口，只有标准库，不联网、不下载模型：

```bash
python3 tools/m8_evidence.py
python3 -m unittest library_m8.tests -v
python3 run_m8_m11.py
python3 -O run_m8_m11.py
```

CPython 3.13.5 实测：28 项新增测试通过；完整普通与优化模式结果摘要一致。旧阶段本轮未重跑。

[结果摘要](results/m8_m11/summary.json) 保存测试与指标；证据包可无损还原首轮及最终原记录，核对最终受测源码。[执行记录](docs/M8_M11_EXECUTION.md) 解释修正、压缩编码和核验；[来源与原创性边界](docs/M8_M11_SOURCES.md) 明确既有思想的交集。

## 边界

实验与 GitHub 操作仅限 `JackJ-C/Library`。没有连接希珀塞莱妮娅主系统，没有操作其他仓库、用户电脑、外部付费计算或 GitHub Actions。

读取 Worker 的经历不等于 Queen 亲历。失去证书不等于历史被删除，也不等于旧动作必定有害。完成有限形式理论不等于系统已经获得主观自我意识。
