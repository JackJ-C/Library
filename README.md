# Library：希珀塞莱妮娅的图书馆研究

重新访问过去的行动、判断和依据，并检验现在凭什么改变程序。唯一实验仓库为`JackJ-C/Library`。

## 当前进展：M0–M32 / v0.8

**M29–M31的有限接力实验通过；“所有更高层造工具规则和搜索原理都已自主创造”未通过验收。** 生成的find和flatmap实际参与后三代自己的再生成，并接入M25重新生成工具构造器与反馈提案。三代代码相同，属于再生，不是能力提高。

M32总体审查发现：多个阶段仍是独立原型；旧M8证书适配器没有自动接入旧runner；M25许可失效不自动阻止执行；完整历史测试和原档核验仍有本轮未覆盖部分。不能将M编号增长理解为这些问题全部解决。

## 运行

```bash
python3 run_m29_m32.py
python3 -O run_m29_m32.py
python3 tools/verify_m29_m32.py
python3 tools/audit_library.py
```

只有标准库，实际环境CPython3.13.5。普通/优化模式内容摘要相同。审查器会列出缺失套件，`--strict`在缺失或失败时非零退出；核验通过不代表理论强目标通过。

摘要和核轨迹在`results/m29_m32/`，完整标准XZ原档在本轮独立运行包。Git-only使用者须先运行实验生成原档后核验；没有把摘要冒充完整原始证据。

最终原档SHA-256：`02162b0a0436fe7cbbb7c91b3c9a564dcf3fbdadc4feb9b56b06f039f76e70a9`。新包位于`library_m29/`，依赖保留的`library_m25/`；新`GatedQueen`须显式使用。
