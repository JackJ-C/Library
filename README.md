## 一个实际过程

```text
只有两个初始观察 → 候选 x
收到反例 (-1,1) → 候选 abs(x)
收到反例 (-2,4) → 候选 x*x
检查域内全部通过 → 真实部署
后来遇到 (17,290) → 原平方程序失效
基础搜索到边界 → 生成 1[x=17] 守卫残差 → 重新检验
```

最后两步属于另一个带隐藏分支的任务；不是把最终挑战答案偷偷塞回前面的平方任务。每一阶段都留下旧预测、新观测、候选表达式和许可状态。

## 对照和失败仍然保留

相同算子库下，学得、默认、逆序各解决24任务，分别尝试27911、39575、26632次；逆序优于学得计划。相同信息的普通JSON历史与主方案打平。无抽象基础枚举在原节点界及补充更大节点界内均未取得可采用程序，这是未解决/拒绝，不是24个错误部署。

新分支若只发生在未检查输入71，程序仍然错。完整检查域、先验、抽象构造器、观察参照及资源预算不能省略。全球原创性仍未建立；程序库学习和反例引导合成已有先例。
