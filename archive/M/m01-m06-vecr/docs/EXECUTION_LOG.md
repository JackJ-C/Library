首先在 GitHub 冻结 M1–M6 合同，提交为 `5bb97212419515f7bf2e3c0a9df0fbb2b35f75e3`。随后在会话执行环境中创建 `Library` 工作目录、实现代码、运行小规模检查与全集实验。没有调用 GitHub Actions 或用户机器。

随后补充全部查询子集的精确计算和双 Worker 扩展，重新运行。它们是主实验后的扩展核验，不冒充事先独立保留的自然任务。

## 原始数据

`results/m1_m6_latest.json` 保存主结果、源码摘要和原始数据摘要。`results/evidence_parts/` 的四个 Base64 分片合起来是一份 XZ 压缩证据包，包含最终结果、逐世界 CSV、1536 条变化 CSV、示例轨迹、测试日志和先前运行摘要（含失败）。压缩包 SHA-256：

`b8cc833b46e28123eb2395c8b98fcd7b2edfb1a057d76dc0eb1d2576dfd9d823`

运行 `python3 unpack_evidence.py` 会核对压缩包摘要，将证据还原到 `results/m1_m6_evidence.json`，不执行包内代码。分片只改变交付编码，没有改变任何研究数据。最终运行摘要与逐世界数据保持原样。

完整 16384 行随机数据可由固定种子复现。结果还保存每个种子的查询数，代码检查其在全部世界相同；主结果记录完整 random.csv 的 SHA-256。没有把重复的世界当独立随机种子。

运行器会在 `results/m1_m6/<结果摘要>/` 写出全部未压缩原始文件；已有不同内容时拒绝覆盖。测试日志含耗时，复跑时保留首次日志而不要求耗时相同。压缩证据包中的早期摘要是历史记录，当前代码用于复现最终结果，不声称能直接复现所有早期版本。
