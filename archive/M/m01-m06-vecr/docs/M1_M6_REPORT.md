## 逐阶段结果

| 阶段 | 完成内容 | 证据 |
| --- | --- | --- |
| M1 | 自动行动、留痕、读取及再判断 | 全部 256 世界的互动运行；示例轨迹含对旧判断的引用 |
| M2 | 盲参数诊断与区分性探测 | 256/256 正确，每次 4 个探测；随机干预 16384 次运行平均 8.171875 |
| M3 | 有界校正、独立检验、持久部署 | 192 次采用，64 次不改；部署后 2048/2048 有限任务正确，修改前 1280/2048 |
| M4 | Worker/通信/Queen/环境归因及跨 Worker 共享 | 单路径 256/256 完整识别；双 Worker 1024/1024 完整识别 |
| M5 | 历史适用性随变化范围迁移 | 1536 个变化事件正确；Worker 变化后 2 次再诊断、环境变化后 0 次 |
| M6 | 形式推导、探测下界、反例与原创边界 | 65536 个查询子集及 343 组修复集合穷举；模型外反例全部留档 |

单路径的端到端校正不要求知道各故障具体落在哪个模块：4 次探测之后还有 16 个兼容世界，而完整识别用 8 次。双 Worker 共享部件约束但不合并经历，10 次识别完整系统；分别从零识别为 16 次。

M5 的 1536 次事件分为 Worker 变化 768 次和环境变化 768 次。变化范围是可信输入，不是算法自己识别出来的。Worker 变化时盲目保留旧校正全部错误，独立门禁全部拒绝；环境变化不影响预先定义的内部校正目标，所以不需要重查这一目标。

## 同样重要的负结果

普通完整日志在相同信息、相同推断器和查询算法下，256 个世界完全打平。没有证实切片关系图或递归观察自身的独立性能贡献。被动重复完整路径的旧证据始终存在歧义，系统全部拒绝确定修复；这是缺乏区分性干预，不是经验回放理论被否定。

加入一种诊断模型未包含的非线性故障，256 个世界都产生错误但确定的提案；组合情境下的独立检验全部拒绝。系统并未自动学会新的机制族，这正是下一步的缺口。

## 指标不能怎样解释

这些不是 256 个自然任务，也不是 16384 个独立随机种子。随机性仅来自 64 个查询排列；同一排列在不同线性世界的停止步数相同。均匀随机排列的解析期望另由所有查询子集精确求得，为 126692/15015≈8.437696，不等于那 64 个种子的样本均值。

2048 个任务是中性受控环境下，每个世界的四种情境与两种载荷。评价端能中和环境，诊断器不能使用该接口选方案。内部修复不保证原始扰动环境的总成绩提高。4 次的最优性仅限预定诊断接口，不包含另外 16 次旧/新验证调用与 8 次部署后审计，也不是 CPU 或内存最优性。

持久变化仅是二位输出校正，不是发明新网络或任意改写源码。观察者的诊断算法和评价规则没有改变。对旧复查记录的递归引用可以审计，但本轮没有证明它改变了学习能力。
