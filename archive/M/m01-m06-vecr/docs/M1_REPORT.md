# M1：可运行的微型图书馆

状态：有限互动与自动再判断完成。公共模型族是 256 个二值传递世界；具体参数不给诊断器，只能经终端传感器获得观测。无需大模型。

每次查询自动生成 Worker 行动、终端观测和 Queen 复查记录；复查保存兼容解释数量、此前与现在的候选校正、状态和反驳条件，并引用前一次复查。记录是序列化快照，读取保留来源和作用域，未来记录与不存在的引用被拒绝。

与 M0 的手工例子不同，这些判断由实际互动、过滤和规划生成。`example_trace` 保存世界 85 的完整过程；世界真值仅在评价者字段出现，不属于 agent_trace 的输入。

实现：`library_m1plus/engine.py` 的 World、Trace、Model、episode。M0 代码没有被替换，新实现只承担本轮有限场景；它不是通用持久数据库或进程安全沙箱。

边界：旧复查的引用能追溯修订，但诊断算法没有靠阅读旧复查链自我改写。自动记录判断变化不等于已经实现自我意识。
