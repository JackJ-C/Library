# M4：归因与不同 Worker 的证据

状态：简化受控世界中的完整归因及双 Worker 扩展完成。

单路径内，算法识别 Worker、通信、Queen 执行通道和环境的全部八个未知位；256/256 世界正确，均需 8 次探测。端到端修复仅需 4 次，但仍有 16 个机制解释，不能声称已定位每一处故障。

双 Worker 实验让 A 和 B 各有自己的 Worker 参数，共享通信、Queen 通道和环境，共 1024 个组合。先识别 A，再将 B 不共享的 Worker 参数重新开放为未知，只继承共享部件的证据约束。全部组合正确，8+2=10 次探测；分别独立识别两条路径为 16 次。十个隐藏位也给出十次二值探测的最坏下界。

另有 256 组来源混合反例：A 与 B 的原始轨迹在忽略作用域时相互矛盾，而各自读取时一致。需要共享的是经可信拓扑映射后的约束，不是把 A 的经历直接改成 B 或 Queen 的亲历。

这些结果以共享关系已知、干预准确和环境稳定为前提，不证明系统能自行发现拓扑，也不构成真实多机器人通信性能结果。
