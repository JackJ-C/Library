# M6：条件理论、精确下界与反证

状态：候选理论 v0.2 与有限核验完成。详见 `THEORY_v0.2.md`，不将工作术语当成首创证明。

理论以兼容机制的允许修改交集为修复核，以声明变化范围的保守映射决定旧证据适用性。证明了修复批准的条件、迁移保留真实机制的条件，以及当前查询接口中的四次修复探测下界和八次单路径归因下界。双 Worker 的十次界同样达到。

全部 65536 个查询子集已穷举：大小小于四均不充分，四元子集中有 16 个充分。对均匀随机查询顺序，精确平均停止数为 126692/15015≈8.437696。另检验 343 组修复集合，其中 6 组两两相交却没有全体交集，排除了一个容易错误使用的判定捷径。

两条反证保留在主结果中：普通完整日志完全打平；模型外非线性故障导致诊断器错误自信。独立门禁成功拒绝后者，不等于诊断器已获得新理论。

成立范围是封闭、确定、可控的机制族。开放式能力演化、递归自观察的独立作用和全新认知架构仍未得到证据。下一编号是 M7，尚未执行。
