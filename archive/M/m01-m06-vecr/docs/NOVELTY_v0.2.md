# 原创性核对与主张边界

本轮进行有针对性的原始来源核对，不是系统性全球查新。没有读取任何其他 GitHub 仓库或复制外部实现。

最直接的重叠来自 Javdani 等的决策区域识别：研究选择测试，将所有兼容假说收敛到允许同一决策的区域。因此「无需识别完整机制，只要足以选择动作」及其静态集合条件不单独主张原创。原出版页：https://proceedings.mlr.press/v33/javdani14.html 。本轮没有复现其 HEC 算法，不能声称优于它。

Bongard、Zykov、Lipson 的机器人自建模研究已展示通过动作—感知关系适应损坏，说明「利用自身行为发现并补偿不足」不是新的总方向。核对原摘要：https://pubmed.ncbi.nlm.nih.gov/17110570/ 。没有据此判定其为该方向唯一或最早的工作。

Everitt 等明确形式化策略与效用修改，并区分固定学习程序中的状态变化和策略程序的修改。本项目固定诊断器加二位校正更接近有界自适应，不把它冒充任意源码自修改。核对正文第 3 节：https://arxiv.org/html/1605.03142v1 。

2026-09-08 的 Safe Harness Self-Evolution 预印本已讨论候选生成、验证和安全采用的不同限制。本轮只核对官方摘要，不借其未经复核的定理给本项目背书：https://arxiv.org/abs/2609.08175 。

因此 v0.2 暂把候选贡献放在一个可检验组合：带来源的跨版本证据、依赖范围决定的历史适用性、修复与归因的不同停止条件、独立验证及持久部署。新写了一份框架不等于证明框架全球新颖，组合的原创程度仍需更广查新。

主实验还直接否定了当前实现对普通完整日志的严格性能优势。递归复查引用目前主要提供可追溯性，尚未证明它改善观察者自身。比喻与术语不能替代这种差分证据。

下一阶段应优先测试机制族不完备、变化范围未知、噪声与探测不可控时的行为，并让观察者真实利用旧复查记录改变自己的观察策略。不能只把当前小世界放大，再把更多重复样本写成更强智能。
