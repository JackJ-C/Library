# M1：自动留痕与再观察

## 结论与范围

确定性微型世界已经运行，不再用 M0 的手工句子充当系统行为。实现位于 `library_experiments.py`：模拟器 `World` 逐阶段执行 Worker、通信、Queen 和环境的二值作用，诊断过程 `diagnose` 只通过观察回调取得输出。公开模型族是设计者提供的，真参数不传给诊断函数；这不是开放世界的未知机制发现。

一个探测循环自动产生 Worker 的行动记录、观察接口的反馈记录和 Queen 的复查记录。反馈保留来源与目标版本，复查指向所有本轮已知反馈及上次复查。Queen 会读取旧判断的可选修复集合，再用新增证据重算，写明是否改变、是否需要补测、什么后果会反驳当前结论。后来的 Queen 没有把 Worker 的行动改写成自己的经历。

记录只保存最终可见反馈，诊断器看不到中间隐藏参数或中间数值。本实验的角色是软件分工，不是已经出现了独立意识或复杂多智能体。

## 实际证据

全部 256 个参数世界完成自动流程；主策略每个世界产生 12 条记录（4 次行动、4 次反馈、4 次复查）。内容寻址主归档的 `automatic_trace_example` 保留第 109 号世界的完整自动切片链；`world_rows` 保留全部世界的探测、最终候选和执行结果。

正反例测试覆盖：复查引用旧复查、读取来源不混淆、未来时刻拒绝、错误版本拒绝、嵌套数据快照。冻结数据类和只追加公共接口是程序约定，不是抵抗恶意同进程访问的安全隔离；来源字符串也不是物理真实性认证。

## 没有被证明的部分

本轮再观察得到新的判断主要依赖新增反馈。没有证据表明无新增信息的无限递归能够产生智能，也没有证明三维空间布局更好。M2 的同信息普通日志是必须保留的反对照。
