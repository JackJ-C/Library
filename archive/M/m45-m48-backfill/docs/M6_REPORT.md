# M6：条件命题与有限穷举

理论主体见 [版本—目标约束的再观察理论](LIBRARY_THEORY.md)。M6 不把已有数学换名当原创，也不把测试通过等同于普适能力。

本轮对 16 项查询的全部 65,536 个子集进行穷举：确定内部校正的最小子集大小为 4，完整确定参数的最小子集大小为 8。最小的 4 查询修复子集有 16 个；最小的 8 查询完整识别子集有 3,136 个。

该检查用全零真实世界的约束集合计算。对固定线性模型族，任意其他可实现反馈集合是齐次解集合的平移；能否区分校正以及剩余维数不随平移改变。这个条件说明负责把有限检查推广到该族所有反馈，不推广到非线性或噪声环境。

手工证明给出更一般的有限候选条件：若兼容候选非空，能够基于当前证据保证满足合同的修改，恰为所有候选的可接受修改集合的交集。这个条件不要求识别唯一世界，却要求真世界在候选集合内、证据正确、评价合同明确。

反例证明了限制不是装饰：普通日志等价、被动观察不可识别、模型族外错误自信、错误干预标签导致错误归因、跨版本直接合并导致矛盾。M7 再加入目标不一致反例。

证据等级：程序实际运行 + 有限全集穷举 + 人工条件证明。没有 Lean/Coq 等证明器核验，没有跨任务性能优势，也没有完成全球原创性检索。
