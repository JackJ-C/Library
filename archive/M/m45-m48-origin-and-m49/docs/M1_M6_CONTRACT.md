# M1–M6 实验合同

本合同承接 M0，于 2026-09-10 在实验实现和运行前冻结。仅 `JackJ-C/Library`，不改旧合同、旧代码或旧结果。结果不决定是否承认里程碑完成：负结果和反例同样是研究产物；未实现的功能不算完成。

## 实验边界

先构造一个完全可穷举的二值传递世界，而不是接大模型。三个可干预内部阶段分别代表 Worker、通信和 Queen，另有一个不可修改的环境阶段。每阶段有一个未知的二位线性响应，作用于二位情境；总计 256 个可能世界。公开模型族和干预接口，不向诊断器提供真实参数或故障名称。确定性、可复位、干预准确以及模型族覆盖真实世界，都是显式假设。

诊断可查询两个基向量情境；情境组合与另一载荷用于独立运行评估。候选修改限制为 Queen 输出的二位校正，并非生成新架构或任意代码。目标先定义为内部整条路径的正确传递，不能用补偿环境错误冒充修复自身。评估在受控中性环境执行；环境不可中和时，应承认该检验需要额外实验条件。不能把端到端校正冒充各模块逐一修复。

## 分阶段交付

M1：确定性互动世界、自动行动及记录、来源和版本、Queen 自动再判断，输出可追溯切片链。原 M0 的手工示例不充数。

M2：诊断器从观察形成候选解释与不足对象，并在信息不足时自主选择区分性探测或拒绝确定结论。与被动完整回放、随机干预和同信息同算法的普通日志实现比较。完整日志打平必须公开，不得当作 Library 的胜利。

M3：实际应用有界校正，独立执行未用于诊断的情境，并检查保持项。全部 256 世界均纳入，包含没有内部净故障的世界；报告修复、拒绝、退化、探测次数和候选评估成本，不筛成功种子。

M4：在同一世界族中区分 Worker/通信/Queen/环境参数；端到端修复与完整归因分开报告。分别测试缺少干预、来源错误、未来证据或证据不一致的影响。

M5：旧参数经过已声明版本事件发生变化后，比较全丢历史、盲目沿用历史及按变化范围保留兼容假说的办法；包含环境变化和内部阶段变化，记录再识别成本、错误迁移及拒答。它只验证操作性连续性，不验证哲学身份或自我意识。

M6：综合上述证据，给出有明确假设的形式命题、证明和有限穷举核验；核对与已有主动诊断、决策区域识别和安全自修改的重叠。不得把已有数学换名当成全新理论。候选理论必须同时列出已支持部分、被反例否定部分和仍未证明的原创主张。

## 固定对照与失败处理

主要世界为全部 256 个参数组合；随机对照使用种子 0–63，保留每个种子的结果或其可复现记录。探测上限为公开查询集合大小，不允许无限重试。优化目标、查询集合、候选修改范围和测试情境在代码里固定，不根据未见测试调参。

至少报告四项反证：普通完整日志能否等价实现；仅有被动证据能否归因；模型族遗漏一种非线性机制时会否错误自信；不同版本的历史直接合并会否误导。测试未知模型族时，须把开发者设计的反例与自动检测能力分开。

输出必须包括中文各阶段报告、理论说明、标准库运行入口、源文件摘要、原始逐世界结果或可复现的内容寻址归档。仅能把亲自执行的命令报告为已运行。验收不要求统计显著性：主实验是有限全集穷举，不声称外推到自然任务。观察数量优势不等于 CPU、内存或总成本优势。
