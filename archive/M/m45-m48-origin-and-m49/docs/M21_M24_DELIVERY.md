# M21–M24 交付位置与档案说明

GitHub 主线包含本轮源码、冻结合同、中文报告与理论、最终完整原始 XZ 数据、摘要、测试及复跑日志。

首份完整实验与最终实验只有证据核验器源码摘要这一项不同，所有任务数据相同。仓库保留精确字段差量、旧核验器源码及无损恢复入口：`python3 tools/restore_m21_first_record.py`。恢复过程不调用任务或学习器，逐字节核对首份完整原记录和原八份源码快照的 SHA-256。

独立运行包另外直接收录两份完整 XZ 原档、首份源码快照、全部探索 JSON、初次运行日志和 `frozen_learning_state.json`。研究报告/执行记录引用的 `exploration_*.json` 与这一冻结状态文件均在该运行包的 `results/m21_m24/` 内；未把这些体积较大的开发文件逐一上传主线。最终主线原档已经包含两种抽象器的先导结果、所选状态及所有最终任务轨迹，不需要探索文件才能复现最终实验。

本轮独立运行包不包含旧 M16 的代码或旧结果，仅保留其核对日志。验证本轮请使用 `library_m21.tests` 和 `tools/verify_m21_m24.py`；重跑旧阶段应从仓库对应时期取得原材料，不能把新包的自包含性延伸至所有历史阶段。

新旧原档都保留其本来解释范围。源码摘要、检查通过和受控数学目标的完整数据，不等于第三方复现或现实未知机制的普遍验证。
