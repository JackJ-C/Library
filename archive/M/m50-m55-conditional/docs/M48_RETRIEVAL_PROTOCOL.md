# M48：原始历史是否真的参与重新取得能力

A/B之后的接线审查指出：主方案在正常复访时主要调用已编译的缓存，而新学习多数来自当前观察区间。因此另立此补充合同，不能用A/B直接声称已验证久远历史的独立贡献。原算法、A/B合同与源摘要保持原样。

开发只用0–3。本补充工具在新确认C/D之前本地冻结，C为7000–7015、D为8000–8015，两个批次均为16个新完整种子。该实验验证人工设定的缓存丢失事件，不把它称为自然自发失忆，也不把旧A/B重复计数。

每个新试验：同一M41派生Queen依次经历四个场景，保存自己发出的探测和三条匿名真实作用历史，实际执行40个后续任务。随后回到最早场景，删除该场景的已编译控制缓存，保留全部原始历史，并将仅用于预测展示的派生缓存故意设成错误值。对象、判断器和账本不重启。

学习器只知道当前可见场景和收到新的无身份探测接口，不提供正确历史索引。检查它是否从持续账本中重新找到三场景之前的原始证据，以原数据而非错误派生缓存形成控制程序，并在十个之后实际任务中工作。

五臂：library、plain、来源边际化marginal、仅最近观察区间recent、撤回一条最早自身意向withdraw_old_intention。最后一臂由评估器事先撤回记录，不向学习器提供替代答案；该干预必须让旧观察组因缺少对应命令而不能继续支持当前解释。比较恢复探测次数和未来任务，而不是只检查日志中有“读过”字样。

验收：对象与账本连续，原始前缀不覆盖；每臂新任务正确率至少95%；library/JSON/marginal在所有试验真正复用早期意向；去掉该意向的组不复用不完整证据且需要更多新探测；相同信息JSON和边际化不劣于显式归属版本。所有实际原始动作、匹配与任务结果可独立重算。两批不互调参数。

明确限制：最早场景的物理映射保持不变，场景标记是合法的任务检索条件，自身意向保管及同步区间仍可靠。删掉的是派生程序而非所有自我信息。此实验可以支持“没有提供特定见证索引也能重新检索旧证据”，不能支持“没有任何线索/上下文的无条件身份发现”。对未经探测的环境变化没有增加新的保证。
