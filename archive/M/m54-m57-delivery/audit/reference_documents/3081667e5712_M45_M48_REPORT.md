# 从匿名作用证据到未来控制

## 本轮结论与交付状态

M45–M48完成了一轮新的限定实验及接线审查。进展主要有两项：第一，Queen不再接收正确的历史见证索引，而是根据当前场景，从持续账本中检索自己的发令和匿名效果，联合判断可能的来源及作用规律。第二，这些相容约束真正进入后续可执行控制程序；不再只是旁边另做一张身份问答成绩表。

这些结论不能扩大为无条件自主身份发现。“当前场景”“同步观察区间”和“可信自身发令记录”仍然是前提。外部相机在同一观察区间内能跟踪三条路径，下一段才重新排列；不是完全无序的现实视频。两个其他控制者的行为确实经过物理更新，但它们是固定实验策略，不是两个完整自主智能体。

完整研究在本地执行。GitHub当前连接提供48项读取类动作，没有发现写入动作；插件发现也只返回已安装的GitHub连接，命令行访问该仓库又因无法解析主机失败。因此本轮**没有新远端提交、没有创建新PR、没有更新已有分支**。基线仍是`JackJ-C/Library`研究提交`a107e655e5a5c4d9dd00a3032ee8d190c8eea4a6`。交付含完整原始证据、可复现代码和仅新增文件的补丁，不能把它说成已经推送。

## M45：不再给正确历史索引，也不提供其他作用者的命令

上一阶段的归属题给出了特定历史线索和两个候选。新接口中，Queen接收当前可见场景和无身份探测端，不接收“请读第几条正确经历”。它扫描自己的持续账本，选择同场景、仍在适用范围内的意向与观察。

每次探测先在本地留下实际命令，然后三个控制源都真正行动；两个Worker产生三条路径的前后位置记录。匿名观察里**没有任何控制者的命令、作者、名字、ID、程序指纹或历史引用链**。Queen只知道自己刚才确实发出了什么，必须考察哪条效果轨迹能够在某种可能的机制下与它相容。

三个路径的排列每个观察区间重新随机化。位置整体平移和路径的六种排列不应改变推断的实质。程序测试检查这些对称性，而不是以“输入字段没有叫author”就宣布排除了所有信息泄漏。

本轮小世界仍用五位置环。动作0不移动，其余四个动作与四种非零位移构成一一映射，共24种可能机制。四个可见场景循环出现；每条主轨迹同一个Queen持续16阶段。第8和第10阶段发生未通报的机制改变。初始阶段是四个场景模型的建立，之后是两次旧场景的重建：**每条六次建立/修订，不应全部称作六次故障修复。**

M41的持续对象和账本、M12的实际感知判断函数、M8的依赖撤销被复用。新改变发生在Queen实际调用的控制函数，函数体由相容模型导出的逆控制表生成。它不是修改模拟器真值，也不是评分结束后另外加补偿数字。本轮没有重新穷举旧M44全部自身判断/Worker故障组合。

## M46：相容关系进入动作，配对干预产生实际差异

对每个已取得许可的场景，以同一个Queen、相同对象初态和相同目标，执行三个配对条件：使用实际相容约束；移除发令—匿名效果的来源相容约束，退回完整先验；恢复原控制绑定。

删除约束时，程序不随机猜一个作者或强制使用错误模型，而是采用所有剩余模型共同允许的动作。完整先验只有原地不动得到一致支持，其他任务会被阻止。这个干预证明的是**来源与效果的对应信息影响了可执行动作覆盖**，不是一个独立的语言标签“我是我”产生了神奇作用。

| 配对条件 | 正确完成 / 总请求 |
| --- | ---: |
| 原始相容约束 | 10,100 / 10,240 |
| 去掉来源相容约束 | 2,048 / 10,240 |
| 恢复原绑定 | 10,100 / 10,240 |

被阻止执行不是错误命令，但不能算任务完成。原路径的140次真实错误同样保留；恢复原绑定重现原来的成功和错误，不是根据答案修饰结果。配对世界重新布置对象只是匹配反事实初态，Queen和判断器没有替换。

必须保留一个很强的反面结论：不单独持久保存`identity_beliefs`、但仍计算相同来源—模型相容关系的“marginal”对照，任务结果全部打平。它不是一个完全不推断来源的独立算法；实现仍计算兼容路径。由此支持“独立身份状态列表并非本实现必要”，不能支持“任何归属处理都没必要”。

## M47：超出旧线性方向模型，但没有实现任意机制修复

例如，种子5000在场景1遇到的实际动作效果为`[0,2,1,4,3]`。这不是一个固定正反方向或线性倍数。第一轮命令1之后有两条可能来源、12个模型；命令2之后来源缩为一条、模型还剩两个；命令3后才得到唯一映射。系统把导出的逆控制函数放进后续任务入口。

这是一项真实的非线性控制扩展，但24种候选是研究者事先提供的。程序没有自己创造新的输入变量、一般表示语法或假设空间。不能因为它生成了一个新的有限表函数，就把“未知机制的开放式修复”标成完成。

压力试验进一步区分：

**完全模仿、效果也相同。** 三条历史都仍可能来自自身，来源不能唯一确定；但是三条解释要求同一种控制，五种目标位移都能正确完成。确定动作不要求确定作者。

**完全模仿、效果不同。** 三条历史均与某种可能机制相容，主动探测耗尽后仍不能唯一决定。该具体例子仅两种目标位移有共同动作；另三种请求被阻止，没有错误执行。模仿者能够响应自己动作的条件与主实验独立行动不同，结果单列。

**实际作用依赖未建模的位置。** 初始许可会放行；当效果在位置4发生额外变化，未来任务真实失败，当前许可随后撤销。此项没有被修复成功，本轮并未提出或验证新的位置依赖模型。安全停下不等于已经学会新机制。

## 强对照、成本与不利结果

| 方案 | 后续正确 / 10,240 | 新探测请求 |
| --- | ---: | ---: |
| 主方案 | 10,100 | 1,167 |
| 相同信息JSON | 10,100 | 1,167 |
| 不另存归属状态的边际对照 | 10,100 | 1,167 |
| 只取最近观察区间 | 10,100 | 1,167 |
| 固定顺序、每阶段复查 | **10,178** | 1,803 |
| 屏蔽自身发令对应 | 2,048 | 8,192 |

固定复查更费探测，也确实少犯了78次后续错误。主方法少用约35.27%的探测请求，不是全面优于固定复查。全日志与最近区间打平还提示：主任务大多依赖当前区间与已编译模型，不能直接用它证明久远回看带来独立优势。

另有两个较弱对照在原档中保留：把三路效果都当成同一来源的保守pooling会得到不一致并拒绝执行；禁止任何新控制模型采用，则全部没有控制许可。它们不是高级替代算法，不能用来支撑强性能优越性。

所有学习调用用相同上限：8个探测请求、1200次读取、100万次定义的比较/扫描运算、100万被选取记录字节。一次探测实际包含三路动作，不等于一次世界更新。统计中的元数据解析、解释器与完整日志管理不是逐CPU指令计数。

接线审查还发现一个成本比较限制：同对象配对干预只在主方案与JSON对照执行，会追加更多日志，从而提高它们之后的扫描操作数。主任务结果和实际探测次数与强对照一致，但**不应拿总扫描次数或总运行时间声称公平的计算效率比较**。原始数据不改写，这个限制明确保留。

## M48补充：旧记录真的有用，而不只是“曾经读过”

A/B完成后的审查发现，正常复访主要调用缓存，学习大多读取当前区间。于是另行登记补充合同，保持原算法与A/B不变，开发0–3后冻结新的C/D。C为7000–7015，D为8000–8015；各16个新种子、五个配对条件。

同一个Queen先在四个场景中学习、执行40个任务，然后回到最早场景。实验移除该场景的已编译控制缓存，保留所有原始记录，且故意把只用于预测展示的派生缓存设置错误。不给正确历史索引，检查它能否按当前场景检索较早意向和匿名效果。

| 恢复条件 | 新探测：C | 新探测：D | 后续任务总正确 |
| --- | ---: | ---: | ---: |
| 可使用原始历史 | 16 | 16 | 320 / 320 |
| 同信息JSON | 16 | 16 | 320 / 320 |
| 不另存归属状态 | 16 | 16 | 320 / 320 |
| 只看最新观察区间 | 64 | 67 | 320 / 320 |
| 撤回一条关键旧意向 | 50 | 48 | 320 / 320 |

主方案32/32重新使用了三场景之前的实际意向。关键旧意向被撤回时，旧观察组不能继续充当证据；系统需要98次新探测，而非32次，但最终仍能重新学习。这比仅保存一个“review”事件更直接地验证了旧记录的实际作用。

这个补充有意限定缓存丢失、场景物理映射保持不变的条件。给定当前场景仍然是一条语义检索线索，可信自身意向保管仍在。它支持“无正确记录索引的历史检索”，不支持“没有任何线索的主体发现”。

## 接线与检验

新代码仅加入`library_m45/`和相应运行、报告及核验文件；旧M37/M41源码摘要保持。新的任务执行仍检查实际程序绑定与证据许可。撤回实际匿名效果证据后，在同一个主Queen上四个入口停止执行，再获取证据后恢复；64/64主轨迹完成该压力过程。

23项新单元/性质测试通过，旧M37的34项和M41的12项分别重跑通过；不能把重复运行算成更多独立用例。A/B普通模式与优化模式得到相同内容摘要。补充C/D亦在普通和优化模式取得相同摘要。

独立主核验路径不导入Queen、世界或学习循环，重算81,920个含对照后续任务、61,440个配对干预执行、3,715个复用前检查，以及真实三路探测作用。主方案40,966条账本记录的时间次序、证据边和撤销闭包也核对。补充核验重算1,600个五臂未来任务和96个真正较早的证据组。独立指代码路径，不是第三方团队复现，也不是整个程序的形式验证。

## 有条件的理论收获

来源和机制最好一起表示，而不是先武断选“我”，再据此拟合机制。令H(E)为与记录相容的“来源、机制”组合；对目标位移d，只有所有剩余机制都允许同一动作时才执行。只要真实组合仍在H中且假设有效，执行动作就满足该目标。来源仍可有多个。

这类决策相关的信息选择和干预辨识已有研究，不是本项目首次提出。[1][2] 本轮新增的是与Library代码相连的可复现对照、真实效果而非命令标签的接口，以及对原始旧证据可撤回性的实际检验。没有建立全球原创优先权。

**准确结论：有上下文但无正确见证索引的归属/机制检索取得进展；发令—效果相容约束对未来控制覆盖产生可重复作用；较早原始记录能减少缓存丢失后的重新取证；显式独立身份状态、无条件主体发现和开放式未知机制修复均未被证明。**
