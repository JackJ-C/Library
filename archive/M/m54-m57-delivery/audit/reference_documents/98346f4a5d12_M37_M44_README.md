## 运行

只有 Python 标准库，实际验证 CPython 3.13.5。无需模型、外网、GPU或付费服务。分别执行套件，避免显式适配器在同一进程中改变旧测试默认对象：

```bash
python3 -m unittest library_m37.tests -v
python3 -m unittest library_m41.tests -v
python3 run_m41_m44.py C
python3 run_m41_m44.py D
python3 tools/verify_m41_m44.py both
```

运行包已有完整原档，可以先直接执行最后一条核验，不必重新运行全部世界。仅Git分支默认不包含大体积完整原档，应先执行C/D生成，再核验。原A/B入口 `run_m37_m40.py A` 与 `B` 只用于历史复现，不是推荐的已修补入口。已冻结的 `freeze.json` 不允许覆盖。

主方案与同信息JSON打平。717个可区别历史归属正确，512个对称案例各半；这是可信意图保管与有限二候选条件下的归属，不是无条件自我意识。主后续任务4074/4096正确；全部日常和后续任务为5775/6144，不能称生命周期零失误。64次故意潜伏候选引发的真实错误单列并完成回退。
