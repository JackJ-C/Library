## 最终两批结果

64条轨迹，每条同一Queen持续72个任务时刻，全部至少三次实际修订，共313次。原因诊断377/377正确；在线任务4358/4608正确；采用后的4524个独立评估任务全部正确，健康组件误改与旧成功回归均为0。

归属方面，256个完整视图可区分案例中203个得到确定结论，全部正确；53个因读取预算未找到区别而不确定。128个完全对称案例全部保留各1/2。全部384次请求的确定覆盖率为52.86%，不能只报“确定结论100%正确”。

匿名对照是由实际作用记录和受控替代轨迹构造，不是两个自由智能体的现实身份发现。工程ID、名字、指纹、真作者及历史引用链不进入归属器。普通JSON日志打平，最近切片对照的归属覆盖还略高，没有空间存储独有优势。
