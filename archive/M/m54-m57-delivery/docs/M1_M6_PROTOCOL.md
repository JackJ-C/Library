# M1–M6 运行协议（实现前冻结）

承接 `M1_M6_CONTRACT.md`（提交 `5bb97212419515f7bf2e3c0a9df0fbb2b35f75e3`），不替换原合同。日期：2026-09-10。

## 模型与可见信息

四阶段参数 `(w,c,q,e)` 各取 0–3，表示两个二值系数，全集 4^4=256。内部阶段为 Worker、通信、Queen，环境阶段不可修改。输入为二位情境 x 和一位载荷 b；每个启用阶段逐次异或其参数与 x 的二进制内积。可对三个内部阶段独立旁路；环境不能在诊断时旁路。旁路掩码 m=0–7，诊断情境 x∈{1,2}、b=0，所以公开查询全集为 16 项。

诊断器只接收公开模型族、查询定义、来自观察接口的输出和可信版本事件，绝不接收真实参数。真实参数只供独立模拟器和评估器使用。日志必须记录可见时间、来源、目标版本、查询及观察结果；自动形成的复查记录引用其输入证据与上次复查。普通日志对照获得完全相同的观察、同一模型族和同一决策算法。

## 选择、停止和成本

主策略按候选解释是否要求不同校正，将候选划为四类；每次选择最大化「观察后剩余跨类候选对数量的期望下降」的查询，按公开查询次序打破平局。候选等权是设计假设，不宣称真实故障分布均匀。完整归因策略采用同一规则，但每个世界单独一类。

所有主世界先进行两个全路径被动观察 `(m=7,x=1/2)`。随后比较：仅被动回放、均匀不重复随机干预（种子 0–63）、面向校正的主动选择、面向完整归因的主动选择、同信息同算法的普通日志。每项查询最多执行一次；候选为空报告模型/记录不一致；全部剩余解释要求同一校正才能作确定性校正，否则补测或拒绝。随机种子只是策略随机性，不是不同世界或独立自然样本。

记录真实交互次数、预计算表成本、掩码/候选类计数操作、日志读取和序列化字节数。交互优势不等同 CPU 或总成本优势；完整模型枚举本身不可扩展。

## M3 修改与保留检验

允许修改仅为输出校正 u∈{0,1,2,3}。对候选解释一致支持的 u 才在隔离模拟器应用；保持原评价规则不变。独立评价器将环境中和，以测试内部路径的正确传递，而不是外部补偿。预采用验证为 b=1、x∈{0,1,2}；所有旧版已成功的验证项不允许退化。验证失败回退。随后一次性运行未参与选择的挑战项 `(x,b)=(3,0),(3,1),(0,0)`。挑战集对诊断器不可见，结果不可用于调参或重选候选。本轮是固定线性族的穷举，不是任意场景泛化。

## M4 反证

测试无干预时的不可识别；来源标签不合法与越过可见时刻的拒绝；同一查询相反反馈引起空候选；将 Worker/通信干预标签互换但保持数据自洽的归因失败。后一项检验说明标签格式正确不保证真实来源可信。

模型族外反例：Worker 加入只在 x=3 时出现的非线性项。这是开发者构造的压力测试；诊断输入相同但未见挑战可能失败。另构造只在 b=1 触发的故障，验证回退机制。不得将这些反例说成系统自主发明的新理论。

## M5 变化与历史适用性

从每个旧世界出发，逐一改变四个阶段之一，异或非零增量 1–3，全集 256×4×3=3072 次变化。旧世界先完整识别，三个对照得到相同旧证据；改变阶段的名称对版本感知策略公开，但新参数/变化增量不公开。

版本感知策略保留所有与旧候选在未变化坐标上一致的新候选；全重学策略丢弃旧约束；盲沿用策略保留旧结论不复查。分别按「足够修复」和「完整归因」统计新增查询成本。另强制把新被动观察与旧参数混合，检查不一致。旧历史有效性依赖已声明变化范围准确，不把版本名视为哲学身份。

## M6 命题与证据等级

尝试证明：非空兼容候选集合存在共同可接受修改，是给定证据下保证修复的充要条件；完整识别所有参数可能比识别修改所需的等价类更昂贵；已知变化范围允许投影保留不变量。附不能识别、错误模型族、错误来源、普通日志等价的反例。
