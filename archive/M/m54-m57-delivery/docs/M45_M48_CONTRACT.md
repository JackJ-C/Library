# M45–M48：匿名作用证据进入未来控制的联合检验

日期：2026-09-11。唯一远端范围为 `JackJ-C/Library`。起点是研究分支提交 `a107e655e5a5c4d9dd00a3032ee8d190c8eea4a6`。不操作 main、既有 PR 或其他仓库。本轮工具实际只提供 GitHub 读取，命令行连接 GitHub 也失败，故本合同在本地验证前冻结，并不声称已在远端预注册或推送。交付可运行包和新增文件补丁。

## 要检验的增量

M44仍由评估器提供特定回访线索，历史归属也未进入控制。本轮不再给 `learn` 正确历史索引：Queen按照当前可见场景，在自己的持续账本中扫描并检索自己发出的动作和同时段的匿名观察。输出不是独立的身份问答，而是可用的控制程序和它的证据许可。

M45：从三条匿名、真实执行的作用轨迹中，联合推断来源与动作规律。外部观察只含两个Worker看到的对象前后位置，不含任何作用者的命令、名字、ID、指纹、引用链或真作者。自己的命令在观察前写入独立意向记录。全库检索通过当前场景与共享观察区间对齐；观察区间对三条路径相同，不标记哪条属于自身。来源在每个区间重新排列。

M46：把来源相容约束直接用于后续控制。以同一Queen、同一物理初态、同一任务做事实—移除来源约束—恢复的配对程序干预。移除约束回到完整候选先验，生成保守共同动作，不注入错误作者，也不把阻止执行算作错误命令。该干预同时去除了发令与效果之间的对应信息，不能说成纯粹一个“我是我”的心理标签效应。强对照必须包含不持久保存身份标签、但对来源边际化的等信息模型。

M47：把旧线性控制扩展到更宽但仍预设的有限非线性机制，实测旧信念失效、重建及未来作用。还有作用者完全模仿、状态依赖的模型族外变化压力。这里不是开放式新语言生成：候选族由设计者给出。

M48：核验接口无身份答案、归属与效果的实际依赖、现有门禁与撤销在新路径的工作，以及对照和原始证据。旧M37和M41测试分别复跑，不冒称重跑所有历史主实验。

## 世界与连续性

同一个M41派生Queen、同一M12实际判断器、同一M8账本，持续16个阶段。四个可见场景循环访问四轮。场景是任务上下文，不是隐藏故障标签。第一次建立控制后保留程序和历史；同场景重访可复用，收到后续反证才撤销相应假设。阶段8与10改变对应场景的实际映射，但事件标签、类型和正确参数不输入Queen。

动作域/位置域都是Z5。一个动作0必须保持原位，其他动作到四种非零位移是一一对应；共24个候选映射，其中4个为线性。两个Worker观察三路作用的苹果/茶杯位置副本；Queen控制一路，两个固定策略对照控制者实际更新另两路。它们不是两个完整自主智能体。跟踪一条路径在同一观察区间中的连续性、同区间同步，以及可信自身意向保管，仍是明确前提。

主实验另外两控制者采用独立随机动作；压力条件中它们会完全模仿Queen。每个探测确实产生三路物理更新，主Queen预算按请求计，三路动作数量另核验。任务评分时评估器重新布置对象，模型和Queen不重置。采样位置可能重复；未来检查覆盖本小动作域，不是未知机制族测试。

## 方案与预算

library；同信息普通JSON；不持久保存身份标签的source-marginal；仅最近一个观察区间；屏蔽自身发令对应；把三路证据错误视作同源的保守pooled；固定探测顺序且每场景重查；不采用修订。

每次学习统一上限为8个探测请求、1200个记录读取、1000000个候选/扫描运算与1000000个被选取记录字节。原始元数据扫描与不同上下文解析额外计算只按扫描操作计，数字不是CPU指令/真实总内存/全序列化字节界。固定重查允许消耗更多实际探测，也可能少犯环境漂移错误；不得隐去这个结果。

归属与功能分别评分。记录真实来源是否仍在兼容集合、唯一来源是否正确、控制程序覆盖和实际错误。观察上不可区分的三条轨迹保留三个候选，不要求唯一认领。如果三候选要求同一动作，可以执行；如果要求不同动作，则阻止不具共同支持的任务。此规则不把模仿者自动判为自身。

## 开发及冻结

开发种子0–7，23项新单元测试、M37旧34项、M41旧12项分别运行。开发时修正过门禁压力段的额外真实探测未进入原始物理日志，以及不同观察端重新分配区间导致潜在重号的问题。这些是研究者改动，不是Queen自行修复代码。原开发内容寻址记录保留。

冻结实际源码、核验器、合同和开发种子后，A使用5000–5031，B使用6000–6031，各32个完整随机种子、八方法配对。A不调B；同一生成器的不同种子不是不同研究团队或现实分布。主独立单位是完整轨迹，复跑不增加样本数。

每批主方法验收：所有对象/账本连续且至少三次控制建立或修订；在线未来任务成功≥90%；每次重新推断后的任务实际错误为0、完成率≥95%；真实来源从不排除，唯一归属不出错；JSON与边际模型未来结果逐轨迹一致；移除来源约束使配对完成率降低至少30个百分点，恢复后命令与结果相同；所有支持撤回在同一对象中阻止四个入口并重新取证恢复。

压力组必须保留：同效果模仿时三个候选且可正确执行；不同效果模仿时不错误执行无共同根据的动作；状态依赖的域外变化曾获许可而在未来实际失败，随后撤销。压力结果不能反馈到主族后再冒充新验证。

## 结论不能越界

本轮去掉的是正确回访索引与二候选限制，不是取消一切上下文和自身意图前提。固定的场景/区间对齐和传感语义仍在。显式身份标签可能不是控制成功所必需；若边际模型打平应明确报告。功能收益可能属于来源—模型联合约束，而非独立“自我概念”。

M47扩大的24项族是研究者预先定义的。生成有限逆控制表不意味着自行发明全部表示规则，更不等于任意未知机制修复、完整自我意识或全球原创。新入口使用旧部件，但本轮不同时重新穷举M44的所有自身/Worker故障组合。
