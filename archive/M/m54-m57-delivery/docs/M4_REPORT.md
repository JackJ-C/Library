# M4：归因与证据可靠性

完整归因策略在全部 256 个真实世界上确定 Worker、通信、Queen 和环境的四组参数，每个世界 8 次二值观察。作为对照，内部净校正只需 4 次，因此修复结果不能冒充完整因果归因。

缺少干预时，两个基向量的全路径输出留下 64 个兼容世界和 4 种不同内部校正。重复回放不缩小集合。这里的归因能力依赖可信、可复位的受控干预，不来自“Queen 看到了很多历史”本身。

测试拒绝不合法来源、不同目标版本和未来证据。同一查询出现相反反馈时，候选集合为空，不能因空集合上的全称判断而签发证书。

但语法检查不等于来源可信：将 Worker 与通信的干预标签互换，反馈仍可自洽。全部 256 个世界中，192 个得到错误的完整归因；另 64 个因两组参数相同而不受互换影响。内部净校正仍可正确，因为异或总和不受换序影响。

因此，系统必须把“这条记录的标签正确”与“该标签真实对应那项物理干预”分开。M4 的结果不是现实场景下普适的因果识别保证。
