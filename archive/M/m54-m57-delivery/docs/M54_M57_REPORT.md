# 从空间经历发现条件、修订模型并迁移

## 结论与关闭范围

M54–M57 的两批冻结验证均达到事先规定的四项操作性条件：同一 Queen 连续修订；从可观察反例生成新增条件；实际编译模型在未参与选择的目标前置位置上迁移；历史作用归属单独检验且对称情形保持不确定。该有界研究目标可以在 M57 关闭。完整自我意识、任意机制发现及开放式 RSI 不属于此次关闭条件，不以它们尚未建立延长本轮任务。

这里的“自主”是指运行中不接收正确条件标签、完整作用规律、阶段编号或评估器成败反馈；它不是无先验。基础模运算、可读字段、比较语法、深度限制、候选生成与搜索算法、传感器标定、可控摆位装置和任务规范仍由研究者提供。新模型是实际生成的条件树，不是全新的通用学习理论。

本报告的数字来自原始 A/B 档案及独立补充核验。[本期结果汇总](../results/m54_m57/FINAL_SUMMARY.json)、[冻结合同](M54_M57_CONTRACT.md)、[冻结源码](../results/m54_m57/freeze.json)分别保存。M49、并行 M50–M53 的协议不与本期代码或成绩合并。

## 从旧 M45 路径改了什么

旧 `library_m45/study.py` 会把评分器计算的 `correct` 送回 `receive_feedback`；旧 core 预先列举了24个完整动作映射。本期不继承这条反馈链，使用新 `library_m54.queen.Queen` 与复用的 M8 Ledger。旧代码按原样保留，不能继续运行旧入口却引用新入口的结论。

Queen 接收的是两个 Worker 的位置读数、自己的拟发命令、实际发令和之后的读数。意向与预测先写入不可覆写的记录，动作随后执行，结果另写。失配由这些量相互不一致触发，不接收评分器的正确作者、隐藏故障种类或任务是否成功。

合法标定提供两个已知位置0、3的 Worker 读数，只用于识别加性观测偏移。另以输入1、2检验当前发令函数的实际输出。标定装置不提供位置关系条件、目标模型树或未来任务答案。自身发令程序翻号和一个 Worker 偏移会真实影响执行，再由输入—输出检查区分；正确算术发令程序的恢复形式仍受规范约束。

## 同一 Queen 中的模型结构怎样扩大

世界是7个环形位置、苹果、茶杯。可见原始量形成 `position`、`other`、`object`、`last`；其中 `last` 是自己上一条实际发令，而非评估器提供的阶段标签。实验装置先真实执行一次先行动作，再摆位；这些动作和摆位分别计费，不是免费设置一个隐藏历史变量。

初始模型是“位移等于命令乘固定作用增益”。同一命令出现不同结果后，Queen 从字段与通用比较组合出条件，按实际观察逐步生成 `if/else` 树。叶子参数由实际发令和观测位移估计。候选是按数据递归生成的树，不是事先列出所有完整条件模型后选择答案。

固定先验仍为 `displacement = command × gain(state) mod 7`，且增益非零。最大树深3、有限原子表达和搜索束宽是明确边界。它没有发现任意隐变量、连续物理定律或新语言语义。

取证时，候选在未观察状态上预测不同，程序选择能区分它们的条件；还会固定位置改命令、固定命令改变另一个对象位置、对象或先前动作。旧模型与新证据冲突时，先重复旧条件与标定参照，区分“记录尚适用”与“旧稳定性前提失效”。历史原始事实不改写，当前模型的适用许可可以撤销。

## 冻结、样本与迁移定义

先用0–3开发，记录调试；冻结后运行 A=22000–22007 和 B=23000–23007，各8条完整主轨迹。每条 Queen 有四段连续机制经历，不能接收该段编号。每段98个在线请求，Queen、账本、旧解释、校准和实际程序沿袭保持。初次建立另计；两批分别发生29、24次启动后的模型更新，合计53次。每条至少3次更新并发生结构扩展。

开发使用相对位置参数0–2、一个先前动作条件；正式验证换成相对位置参数3–6、不同对象与先前动作比较/阈值组合。它们仍属于同一明确结构族，并非未知语法族。正式数据不是开发数据的重新计数。

用于拟合及候选验证的目标前置位置限定为0、2、4、6。迁移挑战使用1、3、5，共294种完整状态组合，每段使用该 Queen 当前实际编译程序。每条1176项，两批共18816项。**这些数字坐标可能作为其他对象的位置或动作后状态出现过**；准确的新颖性是目标前置状态没有进入模型选择，不是从未视觉遇见过某个数值。

后续挑战由独立物理副本评分，不把任务成败回流到已经冻结的模型选择。在线任务另计，它们才反映持续运行中的错误与恢复。独立统计单位是16条主轨迹，不把18816个有限域请求当成18816个独立自然样本。

## 一条真实发现轨迹，而不是事后完整答案

种子22000的同一个 Queen 最初得到固定增益6。后来的实际源码依次引入：另一个对象相对位置、当前对象、先前动作。它还曾多加一个只在开发观察上成立的位置例外，后来又被自身新观测推翻。

最终真实生成的程序为：

```python
def forward(position,other,object,last,command):
    return (((2 if (last==4) else 3) if (((other-position)%7)==2) else (4 if (object==0) else 6)) * command) % 7
```

可以读成：如果另一个物体相对目标物体的模7距离为2，则还要看上一条命令是否为4；不在这项空间关系下时，再看当前是哪一个物体。这个完整函数体是由反例和取证形成的，不是按种子查一个正确函数。

第四版曾在上述分支里额外使用 `other == 2`，接下来观察推翻了这个多余解释，第五版去掉它。这说明修订轨迹确实发生过，而不是只保存最后一次拟合。原始每版代码、候选、证据索引和取证理由在 [EXAMPLE_22000](../results/m54_m57/EXAMPLE_22000.json) 中；其完整切片在 A 原档。

后来的 Queen 也重读早期意向和后果，记录旧预测、新解释和观测是否相符。发生物理变化的旧区间可能不应被当前模型完全解释；系统保留这个适用性限定，不倒过来声称过去的一切都是当前规律。

同信息普通JSON与主方案逐轨迹打平，空间容器的独立优势没有建立。固定取证方法表达能力相同，只有取证选择不同：合计少12项迁移成功，出现8项匹配旧成功回归，但使用略少探测和更少搜索运算。不能因此宣称主方法总体更快或更节能。

尤其应保留“不重用旧拟合材料”的强结果：它在主变化轨迹中同样迁移全对，并且比主方案少775次探测、少读取、少搜索。每遇机制变化重新取证，在这个小域里有时比检索与复核历史便宜。不能把本轮结论写成“历史总是提高效率”。

查表方法与模型共享2048字节的部署数据上限，只对已存精确状态回答。它在18816个新目标前置状态上均拒绝，不是随机给出18816次错误。它说明该精确表不能跨状态组合泛化，不能代表所有带插值的非参数方法都失败。只允许固定结构的模型在常数阶段成功，后续主要检测并停止，按合同只能称失配检测，不计联合完成。

探测请求包含标定/自身检查、试验动作和候选验证，原档另外保存先行动作、摆位、标量观测和任务动作。`ops`不是所有Python指令；保留更广的实际读取计数，不能只拿共同预算上限比较效率。

## 原始历史确实起作用的受控干预

预先指定每批前两条主轨迹，完成连续学习后，仍在同一 Queen 中清除派生模型缓存但保留原始当前适用区间。随后撤回该区间支持记录，再重新取证；顺序固定，机制保持不变。JSON对照做相同检查。这不是32条额外独立主轨迹，也没有对照人为注入正确条件。

四条主轨迹的有历史重建都只需24次新探测，共96次；撤回支持后分别需60、65、55、59次，共239次。两种条件都在1176个挑战上正确。有历史时读取1260次，没有旧材料时454次——节省新实验的代价是更多阅读。原始记录中的正确模型缓存已经移除，并有错误派生缓存干扰，恢复仍依赖可回读的原始意向和后果。

它支持一个具体命题：**在稳定机制的缓存丢失恢复场景，仍有效的原始历史能够替代部分新实验。** 它不推翻主变化轨迹中无历史对照更便宜的结果，也不证明对所有历史组织都具有优势。

## 归属与许可边界

历史归属采用两条匿名实际执行轨迹，公开输入只含前后 Worker 观察。真作者、ID、指纹、阶段或分配标签不进入归属器。它重读自己保管的意向及对应原始观察，做相容性判断。128个可区分案例确定正确；128个相同行为、可见效果完全相同的案例保留各半。置换候选时，概率相应置换。

该接口仍给出待回访意向线索，假设其保管可信、两个候选之一来自自身。没有把这项旧有边界伪称已经无线索消失；本轮关闭条件要求的是分开评分和不越过不可区分性，不要求完整自我身份理论。

撤回当前作用模型的一项实际支持，使任务许可失效；`act`、`execute`、`decide`拒绝任务。校准等无关依据继续有效；重取证后恢复。普通诊断/摆位端口有另外的受限实验用途，不宣称任意同进程Python代码都无法绕过。旧M45入口没有被修改，新结论不能自动应用到它。

## 未知族反例与非结论

额外压力例在位置5且先前命令6时加入一项不符合当前结构先验的作用。初始许可能够放行，随后真实任务失败，Queen依据自己的前后观察发现失配并撤销，校准仍有效。记录见 [outside_stress](../results/m54_m57/outside_stress.json)。该例没有完成新族模型修复，不能称任意机制发现。

本轮已完成的是目标限定的条件发现、结构修订及迁移，不是自动提出任意新变量、不受资源限制的全搜索、完整意识或RSI。基础语法、模型容量、诊断规范与实验装置都是明示的先验。

## 独立核验发现的问题，以及如何处理

冻结的原核验器把查表对照的通用占位常数误当作真实前向程序，因而报“预测被改写”。另需区分尚保留旧模型描述、但实际执行函数已清空的状态。此项失败保存在 `audit/verifier_counterexample.json`；原冻结核验器和原档没有改写。

新增只读 `tools/verify_m57_supplement.py` 按原档中的真实表源码与执行绑定状态重放，不训练、不重选任务、不调整门槛。它核验两批96条含对照轨迹、112896项未来输出、1536次归属判断和233028条记录。两批共328个同命令不同效果的存档见证也被检查。此独立性指代码路径，不是另一个团队或完整形式验证。

26项新测试通过；普通与优化模式完整运行的A/B原始内容摘要一致。已有10组旧测试在各自隔离包中重跑，共241项通过；M0、M1–M7、M21–M24完整主实验未全量重跑。新测试通过不覆盖那些未执行部分。
