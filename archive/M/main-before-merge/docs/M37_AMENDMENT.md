# M37：把真实切片证据接入诊断，而不是装饰性回看

日期：2026-09-11。承接 `M33_M36_CONTRACT.md`（提交 `78bbeb8ff79c2ebc5e246528f3bf0b98a1c9e4e0`）。唯一仓库仍为 `JackJ-C/Library`。原受测源码、A/B数据和门槛全部保留，不重写成新版本成绩。

## 为什么不能直接宣告前一轮联合里程碑完成？

A/B两批数值门槛均通过，但随后源码审查发现：原 `_select_history` 对较旧切片的读取主要用于refs留痕，当前诊断依赖缓存候选和最新完整frame；较旧读取本身没有决定诊断。不能把这一点藏在成功率里，也不能把“读过旧记录”当成已经验证“使用旧记录推理”。

原 `library_m33/` 八份冻结源文件保持不变。新增 `library_m37.grounded.GroundedQueen` 作为最终集成入口，继承同一持续状态、世界、实际修订和许可生命周期。原M8 Ledger继续用于真实refs/deps，旧PolynomialReader仍不进入任务路线。

## 新的实际数据路径

诊断从完整候选全集重建本次解释，不能让缓存充当答案。先读取结果切片的感知部分；随后回看此前单独提交的意向切片，取出当时的实际动作、判断输入、预测和版本；把两条原始证据联合用于筛除不相容的自身/Worker/环境解释。没有意向证据时，不从结果切片的冗余展示字段取回同样信息，而应消耗真实自身探测。

再读取旧审查的控制模型，计算当时模型对这次动作会预测什么，并与后来实际作用对比，另写复查。原判断可以失效，但“当时为何如此判断、后来为何否定”仍可作为正确历史认识保存。新证书的证明依赖显式包含本次所用意向和结果；引用旧结论不等于依赖旧结论为真。

这仍不证明所有久远经历都必要，也不要求空间结构优于普通日志。最近切片对照可取得同样意向/结果时允许打平。

原功能与归属两项分别计分；历史匿名视图依旧是基于真实作用经历构造的受控候选轨迹，不能宣称真实世界主体来源的无假设认证。完全对称与状态合流的不可区分性照旧保留。
