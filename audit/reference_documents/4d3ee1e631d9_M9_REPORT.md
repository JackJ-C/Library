# M9：撤销旧依据，但不抹掉正确的反思

## 两种关系必须分开

历史引用回答“我读到了哪段过去”；证明依赖回答“我的结论成立需要什么”。旧 Queen 的判断被反例推翻时，新 Queen 关于“旧判断错了”的复查可以仍然成立。因此不能沿所有引用边一律宣布失效。

实现保存不可覆写记录和追加的撤销事件，另维护当前失效索引。模型假设、条件模型和拟议行动可组成证明依赖链；反例复查可引用旧判断但不依赖旧判断为真。

## 实际核验

全部 1024 个五节点向后依赖图，每个选择五种撤销根，总共 5120 次。增量传播与同信息普通日志全量重算逐一相同；增量过程中合计访问 7992 条后继依赖边。没有据此宣称总计算或内存优势。

遗漏模型依赖的负例会让旧证书错误地保留资格；把全部历史引用也当作证明依赖的负例会误删正确复查。这些负例表明元数据必须正确，不表明程序能自动补全遗漏的依赖。

三世界、三种允许修改的 343 种接受集合配置中，共核验 3087 条候选扩张边。共同许可严格收缩 1656 次，由非空变为空 774 次。反向读取这些包含关系也核验了固定模型下的一致证据收紧性质。

## 理论含义

新证据可能使系统获得更多根据；扩大解释模型也可能使它失去原先根据。两者不是同一种“积累”。撤销证书是重新要求证明，不是修改旧记录，更不是认定旧动作实际有害。

本轮每个结论仅有一份合取依赖。没有实现多份可替代证明的精确维护、实际来源认证或对恶意进程的防护。真值维护已有长期研究，本阶段不申称它的全球首创。
