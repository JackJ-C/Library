# Library：希珀塞莱妮娅的图书馆实验

> 重新进入历史，不仅检查“过去发生了什么”，也检查“过去的判断凭什么成立，以及当前究竟该修改哪里”。

## 当前进展：M0–M15

最新正文：[Library v0.4：有界的因果自诊断与可撤销修订](docs/LIBRARY_THEORY_v0.4.md)。本轮摘要：[M12–M15研究总报告](docs/M12_M15_RESEARCH_REPORT.md)。

**现在有直接的有限实验支持：Queen 的固定元审查部分，能区分自己真实执行的判断程序故障和 Worker 故障，并只修改相应位置。** 这不是整个 Queen 的无可信基础自证，不是意识证明，也没有建立全球原创性。

在2304次盲故障审查中：176次仅自身故障、176次仅Worker故障、1936次联合故障、16次正常全部定位正确，无关组件误改为零。73728个机制—未来输入检查通过。测试条件是预设有限程序族、公开任务规范、可信标定/历史与固定元核，不能把次数当作独立自然样本量。

## 这次比旧实验多了什么？

过去主要改变的是 Queen 对系统的解释模型。这次故障直接在 Queen 实际使用的主体过滤、时期选择和聚合代码中；修订后，同一实例真正重新绑定并执行新判断函数。只修另一方不能解决相应故障。完整干预与限定条件见 [M13](docs/M13_REPORT.md)。

同时发现并复现了旧M8的一项缺陷：合法矛盾观测报错后，旧全域证书仍可能有效。新增 `library_m12.guard.RevocableReader` 在此路径上先撤销证书再报告错误。**原类作为历史实验保留，并未原地替换；使用方须显式改用新适配器。**

普通完整序列日志仍打平。去掉自身历史且不能补测时，系统拒绝确定归因；给机会补回自身证据，又能恢复。当前证据不支持特殊空间介质或无限递归天然更聪明。

## 复现

在本仓库根目录运行：

```bash
python3 tools/verify_m12_m15.py
python3 -m unittest library_m12.tests -v
python3 run_m12_m15.py
```

仅标准库，不下载模型、不联网。本轮实际解释器 CPython 3.13.5；新增24项测试通过，旧M8的28项测试另行重跑，不算作新测试。完整普通与优化模式复跑产生相同内容摘要。

原始逐次记录在 `results/m12_m15/runs/`，为标准xz压缩JSON。摘要在 [summary.json](results/m12_m15/summary.json)，运行过程在 [执行记录](docs/M12_M15_EXECUTION.md)。原档包括失败压力例、四组完整示例及每次未来输入的四格结果；不是只保留成功总数。

## 研究边界

只在 `JackJ-C/Library` 工作，不连接希珀塞莱妮娅主系统，不操作其他仓库，不启动付费计算或自动后台任务。

这套有限理论不等于开放式无限自我进化。元核、评价和历史真实性仍是信任基础；未知代码机制可能躲过检查。元认知循环、主动诊断和程序修复已有研究先例，来源及候选贡献边界在v0.4正文中说明。
