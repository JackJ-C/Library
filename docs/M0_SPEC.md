# M0：从「图书馆」直觉到可反驳的规格

版本：0.1；日期：2026-09-10。对应冻结合同 `M0_CONTRACT.md`。下面的定义是本项目的选择，命题是在给定假设下的推导，优势则仍是待测假说。三者不能互相冒充。

## 1. 原意与最小承诺

原意不是做一个能搜索日志的问答机器人，而是让变化中的 Queen 检查过去的作用过程，包括过去的 Queen 如何观察和影响整个系统。Worker 的经历仍然有自己的来源。

我们先研究「有证据的自我修正」：系统提出关于自身能力的判断，允许证据推翻它，并在外部冻结的检验下尝试修改。这个定义不覆盖所有可能的进化方式，也不等于意识。

用 `a` 表示运行实例，`v` 表示机制版本，`n` 表示追加记录时的逻辑序号。实例、机制、观察来源三者分开。当前小实现采用单机全序日志；未来分布式 Worker 的时钟和消息一致性没有在 M0 解决。

## 2. 十项术语：定义、正例、反例

| 术语 | M0 定义 | 正例 | 不成立的例子 |
| --- | --- | --- | --- |
| 切片 Slice | 有唯一标识、来源实例与版本、事件时刻、可见时刻、记录类型、载荷和历史引用的不可覆写记录；可能不完整或不真实 | W/v0 在时刻 3 发出动作，结果到时刻 5 才可见，分别留下记录 | 一张无来源总分；把未知结果填成 0 |
| 观察者 Observer | 在特定版本和证据视野下执行一次读取及判断的过程 | Q/v1 读取 W/v0 的历史动作 | 有数据库权限就声称已经理解历史 |
| 作用者 Actor | 实际发出动作、改变状态或作出干预的运行实例 | W 发出抓取命令，Q 之后改变调度 | Q 读到 W 的抓取，就把该动作归到自己名下 |
| 再观察 Re-observation | 后来的观察过程针对已保存切片提出一个明确定义的问题，并追加新的判断记录 | Q/v1 重查 Q/v0 当时为何信任 W | 覆写原判断，使历史看起来从未出错 |
| 再观察差异 Gap | 对同一问题、目标范围、证据视野和可控随机条件下的判断差别；不满足条件时返回不可比较 | 两个判断版本对同一冻结证据给出 0 与 1 | 把后来看到答案后的正确率提升计作原决策更聪明 |
| 不足对象 Deficit | 带目标/版本范围、情境条件、证据引用、竞争解释、下一次检验与推翻条件的候选能力缺口 | W/v0 左侧失误，仍需区分执行故障与左侧环境扰动 | 仅凭一次失败宣布 W 的感知模块损坏 |
| 修改 Modification | 在允许变更集合内，从机制 v 到 v' 的可记录提案及应用；检验合同、原始证据不属于该集合 | 修改 W 的一条有界动作规则并保留旧版本 | 改评分函数或删掉失败记录后宣布修复 |
| 连续性 Continuity | 关于版本沿袭、作用来源和历史经验适用性的分项关系判断，不是单个「我是我」标签 | 有应用事件连接 Q/v0 与 Q/v1，并测试旧经验是否仍适用 | 两个克隆代码相同，因此合并为同一亲历者 |
| 归因 Attribution | 在明确候选解释与假设下，判断某机制改变对结果的影响；证据不足时保留多个解释 | 固定环境，替换执行版本后效果改变 | 环境和版本同时变化，只凭前后分数断定是自我进化 |
| 遍历 Traversal | 在指定可见时刻和访问预算下沿切片引用读取子图，并报告未读完 | Q 读自己的复查记录，再追溯到 W 的原始记录 | 到达预算后仍声称已经审查全部历史 |

其中「不可覆写」指原始证据的记录约定，不表示记录永远正确。纠错应新增更正记录并指向旧记录。摘要、哈希或版本名也不能证明传感器诚实。

## 3. 最小对象和可见性

切片写作：

$$S_i=(i,a_i,v_i,t_i,k_i,\mathrm{kind}_i,P_i,\mathrm{refs}_i).$$

`t_i` 是事件时刻，`k_i` 是图书馆获知并登记它的时刻，且 `t_i <= k_i`。旧事件的证据可能很晚才到达，所以历史回放必须按 `k_i` 过滤，不能只看 `t_i`。

`P_i` 是有限、可序列化的载荷，可包含观察、动作、当时预期和已观察到的后果；未知字段保持 `null`。观察到的后果不是动作的因果证明，也不是反事实答案。模拟结果应在载荷中声明来源；M0 不提供自动来源认证。

$$E(h,I)=\{S_i:i\in I,\;k_i\le h\}.$$

实现对请求集合中任何越过视野 `h` 的记录直接拒绝，而非静默混入未来信息。需要读取哪些切片的选择器属于后续阶段；M0 的集合由测试者指定。

**双时刻不等于无泄漏证明。** 它只保证经过这个接口取得的记录不越界；若判断器通过全局变量、文件或随机状态获得答案，仍然是泄漏。真实实验还需进程隔离和输入审计。

## 4. 推导 P1：原封不动地重读，不能凭空得到新判断

假设判断器 `F` 是确定性的，问题 q、全部可访问证据 E、内部状态 v、计算预算和随机输入 r 均不变，则：

$$F(v,q,E,r)=F(v,q,E,r).$$

因此重复读取的差异必为零。这里没有智能结论，只是同一函数同一输入的结果相同。

重要推论：若再观察产生新判断，至少有一项实际改变了：机制/内部状态、证据、问题、计算过程或随机输入。不能把新判断自动解释成「时间本身令系统理解了自己」。重新组合已有切片也会改变显式输入或计算过程，不违反该命题。

反例边界：状态化读者每次读取都会更新内部状态，不满足「v 不变」；不应拿它反驳上述条件命题。

## 5. 推导 P2：差异没有天然的改善方向

令旧判断为 a，新判断为 b，独立检验目标为 y，损失为 `loss`：

$$G=|a-b|,\qquad U=\mathrm{loss}(a,y)-\mathrm{loss}(b,y).$$

取 a=0、b=1。若 y=1，改判有利；若 y=0，同样大的差异反而有害。没有独立后果，就不能从 G 推出 U 的符号。

即使 y 已知，U 也只评价这个明确问题上的改判，不等于真实行动表现、系统整体改进或未见情境泛化。若旧版和新版面对的信息不同，改判效益还不能归于机制变强。

### 项目工作构造：判断版本 × 证据视野的「再观察对照方格」

对同一个问题冻结两份证据 E0、E1，明确 E1 比 E0 多了什么；冻结两个判断版本 v0、v1：

| | 旧证据 E0 | 增补证据 E1 |
| --- | --- | --- |
| 旧判断器 v0 | j00 | j01 |
| 新判断器 v1 | j10 | j11 |

单看 `j11-j00` 混合了多种变化。数值判断可拆为：

$$d_v=j_{10}-j_{00},\quad d_E=j_{01}-j_{00},$$
$$I=j_{11}-j_{10}-j_{01}+j_{00},$$
$$j_{11}-j_{00}=d_v+d_E+I.$$

I 是两个改变的交互，不得硬塞给「自我成长」。这个代数分解不是发明新的数学，也不自动证明因果。对类别、结构性判断，不应强行相减，而要保留四格关系和专门的比较规则。

若旧版无法恢复，或某格证据不存在，该格是 UNKNOWN。不得用当前系统扮演旧版，把猜测填成历史实测。回顾时可以使用 E1；测「当时能否正确决策」时不可以。

这里是第一项值得继续实验的设计：**Queen 不仅保存自己看法的变化，还保存比较条件是否成立，以及比较中缺了哪一格。** 它是否优于拥有同样信息的回放方法，尚未验证。

## 6. 推导 P3：失去的是区分能力，不是「空间感」

设历史 H 经摘要 C 存储，诊断器只能看到 C(H)，且不能额外探测。若存在两份历史 H1、H2 满足：

$$C(H_1)=C(H_2),\qquad d^*(H_1)\ne d^*(H_2),$$

任何确定性诊断器对两者都会给出相同输出，因此不可能同时正确。随机诊断器收到相同输入时输出分布也相同；对等概率的两个互斥正确答案，平均正确率至多 1/2。

示例：按情境位置保存四次结果，H1=(0,0,1,1)，H2=(1,1,0,0)。平均成功率都是 1/2，但失败位置相反。完整关系能区分；均值不能。

限制很重要：这不证明所有压缩、加权、线性表示都失败，更不证明只有 Library 能成功。无损编码、保留任务充分信息的摘要或新增主动探测都可能恢复区分能力。有限精度与任务相关的信息保留才是问题。M0 不从此推出无限记忆必要。

## 7. 推导 P4：同时变了自己和环境，历史可能无法归因

令执行版本 v、环境条件 e 都取 0/1。考虑两个候选世界：

$$W_A:y=v,\qquad W_B:y=e.$$

如果只有 `(v=0,e=0,y=0)` 与 `(v=1,e=1,y=1)` 两条历史，两个世界给出完全相同的证据。读取任意次数也不能区分它们。

对该有限候选集，受控测量 `(v=0,e=1)` 可以区分：WA 输出 0，WB 输出 1。但对于更大候选集，一次探测不一定够；存在随机性和混杂时还需要重复、控制及明确假设。

**两张方格不要混淆。** 第 5 节是「判断版本 × 信息」用于审查改判；此处是「执行版本 × 环境」用于检验实际效果。不能把在新证据上重新解释旧日志，当作新机制在真实环境运行过。

因此不足对象应保留竞争解释和下一项区分性检验。来源标签只回答「谁报告了什么」，不直接回答「谁造成了结果」。

## 8. 推导 P5：递归观察不必是无限自套

令新增记录只引用已存在、追加序号更小的记录。若存在有向环，沿环的序号必须严格下降后又回到起点，矛盾。因此这种引用图无环。

有限历史和去重遍历保证终止；每次再加深度、记录数和序列化字节预算，可限制一次读取的输出。预算耗尽必须返回 `truncated=true`。

这允许：Q/v2 检查 Q/v1 对 Q/v0 的一次观察，而无需把每层历史复制进新记录。新证据是「我进行了这次检查」，不是修改过去。

边界：无环不代表全生命周期空间有界；单次输出预算不等于 CPU、常驻内存或全部解析成本已严格受限。保留、删减、压缩和长期存储策略留待后续实验。M0 的 Python 私有成员约定也不是抵抗恶意进程的安全隔离。

## 9. 不足对象与连续性：不抢答「我是谁」

建议不足对象采用以下契约，M0 只定义、不实现自动生成：

```text
目标：运行实例、机制版本及适用范围
情境：在哪些条件下存在何种能力缺口
证据：原始切片 + 再观察记录 + 比较条件
竞争解释：执行/感知/环境/通信/Queen 干预/记录偏差等开放候选
未知项：还缺什么证据，不得用 0 代替未知
下一检验：哪项可行测量可能区分解释
推翻条件：出现什么结果应撤回这个不足判断
修改范围：允许尝试的部分，禁止触及的评价与证据
```

连续性至少分成三项：`lineage`（哪个版本由哪个修改事件产生）、`provenance`（历史动作来自哪个实例）、`applicability`（这段历史对当前能力判断是否仍有效）。同一沿袭可能产生多个分支；分支相似不等于共享亲历。

M0 参考实现只保留实例/版本来源；不把这些元数据宣称为系统自主识别了自身连续性。后续需要加入克隆、分叉、损坏、恢复等情境，检验连续性判断是否改善行动，而非只输出身份词。

## 10. 一个读得懂的切片链

1. W/v0 在时刻 1 行动；记录结果未知。
2. 时刻 3 收到后果：任务失败。历史决策视野 h=1 不得读到它。
3. Q/v0 在时刻 4 阅读前两条，写下「可能是 W，也可能是环境」。这条记录的来源是 Q，原动作的来源仍是 W。
4. Q/v1 在时刻 5 再观察 Q/v0 的判断，指出还缺固定环境下的版本替换实验。

这只是手工构造的契约示例，不是一个自主 Queen。它展示了怎样把「观察自己如何观察系统」保留下来，同时不伪造过去或提前知道结果。

## 11. M1 以后怎样推翻我们，而不是帮我们赢？

必须比较拥有相同信息和预算的强基线：完整日志+同一判断器/候选修改器、均匀回放、误差优先回放，以及 Library 的关系遍历。只战胜「仅有均值」的弱基线不够。

预先冻结任务生成器、种子集合、可变机制、诊断器输入、比较预算、评价指标与停止条件。开发、修改选择和最终未见测试分开；反复选择的验证集不能继续冒充未见集。没有真实结果的动作变更，不得直接复用旧动作结果来打分。

记录归因准确率及拒答率、修复后的未见表现、旧能力退化、交互/计算/存储成本，不只看总分。做来源、版本、可见时间、再观察引用的分别消融；禁止同时减少基线的信息量和预算。

若完整日志配同一判断器取得相同或更好的结果，且 Library 没有可验证的成本优势，应收缩「特殊组织机制有用」的主张。若去掉递归观察并无损失，应承认这一部分暂未提供作用。若收益只来自额外信息或更多计算，不计作图书馆结构的独立贡献。

## 12. 本轮结论范围

本轮能够完成的是词义、条件命题、最小数据契约和有限反例检查。它们为实验排除明显混淆，不证明机制优越性，也不保证自我进化一定成功。原创候选集中在可检验的组合：**保留再观察的条件与缺格，以不足对象引导下一次区分性观察，并追踪跨版本历史的适用性**。全球首创和经验优势均未建立。
