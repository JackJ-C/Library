# M2：由不足歧义选择下一次探测

状态：已知机制族内的盲参数诊断完成。未直接告知每个世界的故障名称，但可能的函数结构由设计者给出；这不是未知机制族的自主发现。

诊断器保留全部兼容解释，比较它们允许的内部校正。若校正仍不唯一，它从 16 种公开查询中选择两步前瞻下最坏剩余修复歧义最小的下一查询；若证据不一致则拒绝批准。查询并非按当前世界标签手工指定。

256 个世界全部用 4 次探测确定正确校正。随机无放回查询采用种子 0–63，共运行 16384 个世界—种子组合，平均为 8.171875 次，范围 5–13 次。不同世界不构成独立随机重复。M6 另给出均匀随机排列的精确期望。

强基线是完整日志每一步从头重放相同证据、调用相同规划器；256 个世界的结果和轨迹完全一致。因此本轮没有发现特殊 Library 组织的独立优势。

弱基线重复完整路径的两个情境观测到上限，256 次全部拒绝确定校正。单元测试也验证重复同一证据不会缩小兼容集。这不能被解释为对实际经验回放算法的全面评判。
