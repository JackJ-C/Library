# 连续 Queen 的经历、回看、修订与历史归属

## 联合里程碑的结论

**修订后路径 M41–M44 在两批冻结确认验证 C/D 中，通过了限定模型内的联合验收。** 同一个 Queen 连续运行、查验实际判断与 Worker/环境作用、修订其后续程序，并保存匿名历史的归属或不确定性。这不是把不同 M 阶段的独立满分拼起来：每条确认轨迹只有一个持续 Queen、两个持续 Worker 和一份持续账本。

结论受明确条件约束。历史归属是给定待回访的自身意图线索、可信保管发令记录、候选中恰有一条自身历史时的相容性判断。没有证明无身份线索的主体发现、归属认识会提高控制能力、完整自我意识、开放式 RSI 或全仓库所有旧原型已经融合。

M37 开发只用0–7；合同与13份受测文件摘要分别在提交 `002147941c522da4fc298a341346d50e0f3e8eb8`、`aad2db9e038542d008fffd5721463464119ab8cc` 登记。A用1000–1031，B用2000–2031，均满足原冻结门槛。随后交付审查复现两个问题：一项标定证据被撤回后，许可仍然有效；归属意图缓存含评估器提供的绝对位置。

## 一条真正接通的过程

世界为五位置环、苹果、茶杯、两个 Worker。每条轨迹32个窗口，每窗口一项日常请求和两项后续请求；后续请求未进入当次诊断或采用前检验，未来发生后可以进入下一次学习。位置与机制在小域内可能重复，不能称为未知机制族泛化。

隐藏变化含健康、自身判断、Worker测量、环境方向、组合变化；每条六次事件，具体时刻、类型和参数不给 Queen。自身故障直接改变她正在调用的 M12 判断绑定，而不是只在另一个模拟器里命名一个 Queen 参数。系统保存并约束旧假说，遇到矛盾才重新开放相应部分；修复后假说随真实修改映射，不在新任务开始时重新注入正确模型。

Queen按预测矛盾、许可失效或三窗口复查启动调查。策略选择相关作用和结果记录，不够时调用自身判断探测、已知输入标定或两个对象的控制探测。选择器是固定规则，不是另行学习出来的最优记忆检索算法。标定参照、任务规范、候选族和元审查核仍可信。

切片包含原始/解码读数、对象关系、Queen当时输入、实际读取集、预测、事前命令、后续观察与复查。M8的历史引用和证明依赖被实际复用；M12的判断函数和 Worker 解码器进入同一新执行路径。旧记录不覆写，旧错误可以作为新反思的引用对象。

日常请求也必须计分：C为851/1024、D为850/1024。阻止执行不算成功；发生反证前的实际错误也保留。主路径日常与后续合计5775/6144成功，并不是“整个运行零失误”。逐批的正确、错误执行、被阻止执行三项在 `delivery_summary.json` 中，全部由原始动作重算。

统计单位是64条新随机种子轨迹，六方法配对形成384条方法执行，不是384个独立机制族。每批轨迹级10000次重采样区间仅作为描述性补充，不是跨现实分布的保证。两批来自同一模拟器、同一研究者，不能称独立团队复现。

## 历史自我归属没有与修复混成一项

717个可区别案例正确；512个完全对称案例保留 `[0.5,0.5]`，无错误确定归属。可区别案例包括205次真正发生旧命令与当前同输入命令不同的行为变化；没有相应旧经历的请求记为未具备，不伪造变化。两条轨迹可以由不同命令走到相同终态，去掉前驱命令时保持不确定。

匿名视图只保留命令；作者、工程 ID、指纹、时间标签、引用边和原始分配次序不输入归属算法。自身命令从世界执行前的 `queen_action` 取得，M41不接收评估器传入的意图坐标。对所有实际意图缓存，核验器逐项确认其内容恰好是对应事前命令；候选置换只改变概率次序。

**仍保留的前提：** 当前控制端有可信的自身发令记录保管，归属题给出待回访线索，两个候选中恰有一个属于该控制端。这不是从无标记全历史中自主寻找“我是谁”。对称情况下各半来自等先验与不可区分，不是系统把作者猜对了一半。

Q01原文没有从本轮检索取得。本报告不声称复现Q01，独立实现了功能正确而归属不可区别的例子。行为预测相合与主体归属不应等同；相关实验研究也区分作用感与自我所有感，但本程序不是其人类心理实验的复现。[2]

| 方法 | 后续任务成功 | 可区别题确定归属正确 | 诊断探测请求 | 诊断与依赖读取 | 候选/依赖比较 |

| 主方案 | 4074/4096 | 717/717 | 2380 | 5059 | 23583 |
| 同信息 JSON | 4074/4096 | 717/717 | 2380 | 5059 | 23583 |
| 只看最近切片 | 4074/4096 | 0/717 | 2913 | 4395 | 19823 |
| 屏蔽关键自身历史 | 4069/4096 | 0/717 | 3244 | 3244 | 19464 |

| 固定完整重校准 | 4069/4096 | 717/717 | 3244 | 3244 | 19464 |

普通 JSON 在同信息、同算法下逐种子打平；没有空间容器或递归深度的独立性能优势。固定最近切片也能借新探测恢复功能，但不能补回被屏蔽的特定历史意图。屏蔽关键历史后，可区别题不作确定归属是保守拒绝，不是被算成随机错误作者。

不修订对照仍能在其保存的旧经历上完成相容性判断，控制却明显失败。其可用历史随执行轨迹不同，归属题数量也不同，不能把744/744与主方案717/717当作完全相同题目的算法胜负。这个对照用于说明两项能力可以分离。

每审查上限一致：24读取、6探测请求、6000比较。一次标定含两个标量，一次双对象控制含两次实际移动；标量、验证和任务移动另记。M41的依赖登记计入读取/比较，归属自身读取也另记。主方案用2380次探测，固定重校准用3244次，少26.63%，但读取与比较更多；不宣称总计算或墙钟更快。代码记录的是定义的成本代理，不是每条Python指令。

## 反证、撤销与同一对象上的恢复

每条主确认轨迹完成32窗口后，不重建 Queen，再提议一个只在茶杯任务出错的候选。有限苹果验证会放行它；随后一次真实茶杯任务失败，旧许可撤销、真实判断函数回退，四个任务入口禁止执行，再取证后恢复任务。**64条主轨迹因此另有64次明确保留的压力错误**，不并入主支持族分数，也不说从未误判。

随后在同一Queen中撤回实际标定依据，64/64使当前许可失效，四入口均阻止任务且世界不动，重新取得证据后未来任务恢复。JSON对照也经历同样压力段。测试还逐项覆盖所有支持证据类别、结果而非只有动作的依赖，以及旧错误引用不连带撤销正确复查。

环境增益2、跨对象漂移与非线性标定超出主族，开发压力中出现不一致后拒绝修改。未被当前检验看到的潜伏分支仍能先获得错误信心。许可依赖写全，不等于规范、传感器或元核本身无条件可靠。
