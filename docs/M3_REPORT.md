# M3：有界修改、独立验证与持久采用

状态：二位输出校正的自主选择与持久部署完成；不代表源码或架构自修改。

Controller 先从互动证据冻结候选，再调用独立评价端执行旧版和候选。评价在中性环境进行，涵盖组合情境、零输入保持项和基向量回归，均用两种载荷。任何一项失败就不采用；通过后保存新 Genome 和版本，后续 act 使用已经部署的值。再次修复同一正常状态不会无意义增加版本。

全部 256 世界中，192 个采用新校正，64 个无内部净错误而不改。修改前 1280/2048 任务正确，部署后 2048/2048 正确，无有限任务回归。64 个不改不意味着各个内部模块都没有错误：相互抵消也可能使整条路径正确。

成本分开计数：4 次诊断，16 次旧/新验证调用，8 次部署后审计。验证输出不反馈给规划器继续选候选，避免把评价过程偷偷当训练。

加入只在组合情境出现的非线性故障后，所有 256 项候选都被独立门禁拒绝，旧 Genome 保留。拒绝避免了错误采用，却没有完成这些模型外故障的修复。

内部路径校正可能揭示原先被抵消的环境错误，因此不声称原始扰动环境中的整体表现必然提高。任务标准从合同开始就限定为内部路径的正确传递。
