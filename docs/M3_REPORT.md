# M3：有界校正的真实应用

## 固定目标

本阶段仅要求中和环境后，内部整条路径正确传递输入。校正只能为 Queen 输出端的两位参数 u=0–3。它不是生成新架构，也不是逐一修好 Worker、通信与 Queen 的全部内部故障。

诊断只使用 b=0、x=1/2。采用前实际运行 b=1、x=0/1/2 的验证；旧版成功验证项不得退化。验证失败则回退。随后只评价一次未参与选择的组合情境挑战 (3,0)、(3,1)、(0,0)，不把结果反馈给选择器重调。

## 全集结果

256/256 世界完成内部校正与独立挑战；其中 192 个应用非零校正，64 个不需净校正。验证保持项退化 0；没有从全集删去健康世界或错误相互抵消的内部世界。

“256/256”只属于这个冻结的有限线性族。挑战情境虽未用于选择，但线性结构已知，不能据此声称任意新环境泛化。

## 压力测试

当 Worker 存在只在 x=3 触发、候选族没有表达的非线性项时，256 个构造世界全部通过诊断与采用前验证，却全部在挑战中失败。挑战代码能够报告失败，但诊断器没有自动扩展模型族，也没有自主发明新的非线性理论。

当故障只在 b=1 触发时，256 个构造世界的验证都失败并回退。它说明回退路径工作，不说明所有遗漏机制都能被该验证集发现。

## 由 M7 修正的边界

内部传递正确不等于自然环境下整体变好。M7 专门检查这个目标缺口；不能用本阶段的满分覆盖后续发现的外部退化。
