# 来源—机制相容集合与可执行修订

## 有限形式化

一次主动探测留下本地发令序列U，以及三个无作者、无命令的观察路径Y₀、Y₁、Y₂。路径包含两个Worker对对象位置的前后观察。同一观察区间有跟踪连续性；区间之间的索引重新排列。

令F为声明的候选动作规律，本轮是Z₅上的24个零保持双射。定义

H(U,Y) = {(j,f) : 对全部已观测步骤，路径j的实际位移等于f(u)，另一对象没有非预期移动}。

跨场景检索只组合适用范围相同且未撤回的历史，保留每个区间自己的来源索引；不能用“路径0”在不同区间冒充一个永久作者。机制集合是各区间允许机制集合的交集。

## 命题一：唯一动作不需要唯一来源

对目标位移d，允许动作集合为所有相容机制的逆像交集。若真实来源和机制仍在相容集合内，且该交集包含动作a，则真实机制也满足f(a)=d。这是集合包含关系的直接结果。

同效果完全模仿时，来源可有三个，机制却只有一个；所有动作仍可确定。不同效果的模仿者可能留下多个机制，只有共同支持的位移才能执行。两种情形已由真实更新的三路轨迹分别检验。不存在“只要不确定是谁，就什么都不能做”的普遍推论。

## 命题二：删除约束不能增加有保证的动作

若E'删除了有效的来源对应证据，使H(E)包含于H(E')，那么对更大机制集合求共同允许动作，只会保持或缩小原来的动作集合。该结论解释移除相容约束后为何更多任务被阻止。

这不是信息越多必然更好的无条件定理。错误的证据可以排除真实机制，让错误动作显得确定；随时间失效的证据也需要撤销。主实验中的未通报变化和域外位置依赖就是反例边界。

## 命题三：撤销与过去不可覆写可以共存

原始观测留下来，不代表由它支持的许可永远有效。以证明依赖传播撤销，能使当前任务停止；以历史引用指向旧错误，可以形成正确复查而不继承它的真实性。新模型需要新的有效支持，不能用恢复旧程序自动恢复失效许可。

本轮在同一个存续Queen中撤回匿名观测，验证四个任务入口阻止作用，再取证恢复。该性质是当前接口约束，不是恶意同进程隔离或崩溃恢复保证。

## 命题四：原始经历可恢复派生程序，但有条件

当场景机制保持稳定，原始意向与观察仍真实、可访问，派生控制程序的丢失不必等于丢失全部可用于重建的信息。补充C/D显示，实际重读旧证据可以减少新探测。

这不是以同样信息无代价“变聪明”。读取和筛选仍有成本，也有时间适用性条件。缓存被删但原始证据和任务场景尚在，与没有任何记忆、线索或身份前提完全不同。

## 可说与不可说的原创性

数学部分由有限模型、集合交集及条件可靠性直接导出，不是新发明的数学原理。主动检验应服务于决策相关不确定性，已有Javdani等人的研究；时间干预数据的可识别性也已有CITRIS等工作。这里独立实现和验证的是一条Library的来源—机制—控制—撤销路径，未作全球优先权证明。

当前最大的未解决问题是：当真实机制不属于F时，怎样在不偷渡答案的情况下改变F，而不是仅在F内重拟合。新位置依赖状态尚不能修复，因此不能把有限表重建称为开放式RSI。
