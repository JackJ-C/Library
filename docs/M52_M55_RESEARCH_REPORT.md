# 持续空间经历中的条件发现、模型修订与迁移

## 收束结论

**修订后的M53实现，在M54两批冻结确认I/J中通过了本轮操作性联合门槛。M55完成分支、证据来源、旧测试和遗留主张的总审查。** 收束目标是：同一个Queen从实际发令、事前预测和Worker前后观察中发现理解不足，主动取得能区分解释的证据，扩展作用模型结构，并在未用于选择模型的字段组合上检验实际执行。

这个完成结论不等于完整自我意识、任意机制发现、元核完全自主创造或开放式RSI。此类目标不再作为本轮未结束的理由，统一列入另行研究边界。全球原创性没有建立：本轮贡献是独立的连续集成、可核验的反例与分项证据，不把通用语法合成或主动取证重新命名成全球首创。

## 先保留失败，再冻结新的确认

本轮发现既有M49、M50、M51并行登记，没有取得它们所指全部实现及原档，因此新代码从M52开始。M52完整源码与合同在提交`ca89fdde1d30689d7d35c3cf0e0e0cbb052f67c5`中、G/H运行之前上传。G/H均未通过联合门槛：G只有31/32条发生结构扩展，末端4650/4800正确，另有20个旧成功退化；H末端4800/4800正确，但仍有40个旧成功退化。

两个G失败轨迹被用于纠错。一个原因是按几何距离极值取证，漏掉了先前命令的中间值；另一个是采用前出现新反例后，后续复查反复读取同一批不同时期的冲突记录，无法重新取得许可。不能把“检测后停止”冒充完整适应。

M53增加通用字段/两两取值覆盖，单一效果值需至少24个不同取证组合；真实新反例成为下次取证的起点，同上下文不相容时再实际测量，保留旧数据及其失效范围，不覆盖旧历史。修补由研究者完成，不宣称Queen自行重写了这些元规则。

35项开发测试通过后，在提交`d5d509baecc37223fd0cfc5fdfe6ab1ad2b6a18e`中冻结完整增量、合同与新I/J种子。I为331000–331031，J为397000–397031；两个批次之间没有修改代码或门槛。原开发组合、旧M51记录的失败组合和本轮两个纠错组合都排除在新确认条件组合之外。I/J共实际抽到19种组合；它们仍来自声明过的有限生成器，不是不同现实分布。

## Queen看到了什么，没有看到什么

世界只有两个Worker、苹果、茶杯、五个位置，以及先前实际发出的命令。学习器的原始字段是自身对象位置`x`、另一对象位置`y`、先前命令`previous`、对象类型`object`。没有场景编号、阶段编号或正确条件名称作为输入。

任务执行前，Queen保存当时输入、预测和实际命令；动作执行后，接口只返回两个Worker的观察和先前命令字段。`correct`、`success`、真实作者、隐藏故障类型及世界的真实条件表达式只存在于评分器。新`receive`接口对多余字段直接拒绝。自己的预测是否失配由观察到的位移、跨对象变化及实际判断输出与规范的关系决定，不调用旧M45的评估器正确标志。

标定装置允许查询已知位置0和4的两个读数；它提供绝对测量参照，不能被称作无外部参照自证。实验装置还允许真实布置对象、执行准备动作以改变先前命令，再观察一个动作的效果。准备动作、摆放、测量和效果动作都记录为成本。这里不是自然无干预机器人环境。

同一Queen对象保留M12的实际判断函数、M41的持续对象基础和M8只追加账本。当前控制器、偏移校正、原始经历、不同有效期的知识及未排除解释持续存在。新结果不把main的七位置原型和研究分支的五位置原型当作同一个实验。

## 初始模型为何真的不够

初始可表达的关系只有`effect = command × gain mod 5`。当同一命令在不同原始条件下产生不同效果时，不存在一个常数gain同时解释这些观测。程序先记录这个矛盾，再从字段、减法、绝对值、模运算、比较、否定和合取构造条件AST；两个效果系数来自实际观察，而非隐藏规则表。

这不同于直接在旧24个完整动作映射中增加几项答案。但它仍是给定语法内的结构搜索：基本操作、表达式深度、数值域和搜索预算由实验定义。生成时使用有限域语义去重，不能把这一实现称为无限开放的新语言创造。

一个实际生成的表达式为：当`abs(x-y)<2`时，效果增益是1，否则是4。较晚的新反例又将其改为：只有`previous==1`并且`abs(x-y)<2`同时成立时增益是1，其余为4。中间曾分别修订自身判断与Worker解码，并没有每次重置整个系统。

生成后的Python函数实际进入任务执行。所有剩余相容表达式仍作为不确定性保留；部署采用最简表达式，是带撤销机制的归纳承诺，而非所有未见情况都已获得逻辑证明。历史归属不使用这个最简选择强行排除其他仍然相容的作者。

## 历史不只是装饰性引用

每次推断读取原始意向中记录的上下文，并从Worker端点重算效果，不把缓存的gain字段当答案。当前真实字段组合、实际命令和两个端点共同筛除解释。损坏缓存标签而保留原始证据不能改变拟合；撤回一项关键原始意向会使依赖许可失效。

独立压力段在同一个Queen上移除已编译控制器，保留原始历史。主方案和JSON均用7次探测恢复，屏蔽旧历史需要19次；三者后续任务均正确。这里的7次包括重新校准和采用前核验，不是“完全不再测量”。这是一组明确的受控历史因果检查，不把一次构造当作现实总体效应估计。

新模型也重新计算早期记录的预测：旧解释在哪些已观察条件下相容、哪个反例要求补入条件、哪些较早记录属于已改变的物理时期而不应继续强迫新模型解释。旧判断和旧观测不改写，新反思另写。历史引用与证明依赖分开，旧错误可以成为正确反思的对象。

## 自我认识边界与撤回

归属器从同一Queen的实际历史重取证据，接收匿名作用前后观察，不接收真实作者、程序指纹或图边答案。可区分64次全部正确；相同行为和失去前驱区别的合流128次全部保留两个候选，各半。这个结论仍依赖可信保管自身命令、对齐的观察区间和有限候选前提，不是哲学身份或无参照主体发现。

撤回实际支持证据后，四个任务入口禁止执行；重新取得证据后同一对象恢复，旧知识记录及与被撤回事实无证明依赖的历史认识保留。一个有限验证可以放行的潜伏候选，在实际后续任务中出错后自动回退，并再次通过后续检查。模型族外的局部潜伏变化和错误标定参照也保留为压力例。

因此本轮支持“有依据的连续自修订”，不保证所有未知机制都能建模，也不声称任何错误都在发生前被发现。新条件构造、查询策略和可信元核仍有明确边界。
