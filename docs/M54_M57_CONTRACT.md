# M54–M57：空间经历中的条件发现、模型修订与迁移

本合同在开发运行之后、正式A/B之前冻结。唯一仓库JackJ-C/Library；基线材料为a122a5c764bb04d87d2ee8b06ae57ee4a2e89cb4对应M45–M48运行包。主线、并行M49及M50–M53协议不覆盖、不混算。本实验从M54续编，所有旧冻结文件保持原字节。运行于当前会话隔离CPU，无付费计算或后台服务。Git写入若不可用，保留本地冻结摘要和补丁，不追溯冒称远端预注册。

## 收束目标

同一个Queen在连续空间经历中自行发现原模型缺少条件，选择历史和干预，构造新增条件的表达式，生成真实执行程序并在未用于选择的情境上检验。历史作用归属单独评分；完整自我意识、任意机制发现、RSI不属于本合同。

## M54：开发、世界、接口

开发种子0–3。开发期间确实发现过混合历史导致预算耗尽，随后加入：只有原始意向/观察导出的同条件反例可撤回旧适用区间；无一致树时主动复做旧条件。保留开发运行记录，不把开发修改称为Queen自己写出了元算法。另修正了零命令、实际历史记录不能依赖旧理论为真、历史校准快照，以及把采样缓存代替真实读取的计数问题。

世界包含苹果、茶杯、两Worker和七位置环。可见字段为目标对象位置、另一物体位置、对象类别、上一次实际发出的命令。两个Worker各自给出原始位置读数。固定假设为真实位移=a*g(位置、关系、对象、先前命令) mod7，g非零。观测可有稳定加性偏移；自身发令函数可反号。元审查器、加减比较语义和标定装置仍可信。

Port只返回Worker观测，不提供correct/success、作者、故障名、场景或阶段。Queen先保存实际命令与预测，再接收前后观察，自行比较。已知位置0和3的独立标定只确定Worker加性偏移；自身函数输入1、2的检查只约束实际发令运算，不揭示环境条件。

每条轨迹同一Queen、账本、世界。初次建立常数增益模型之后，三个未告知的变化分别引入关系、对象、历史条件；第二次同时混入Worker偏移，第三次混入自身发令故障。每个平稳段98个预先确定、与目标参数无关的在线请求，取目标位置0、全部另一位置/对象/先前动作组合，并随机打乱。没有变化标签传给Queen。调查只由可见失配、Worker冲突或已有许可缺失启动，每段最多6次修订尝试，拒绝与实际错误都计入分母。

条件组合：开发只用相对位置差0/1/2和历史<1。确认用相对位置差3/4/5/6、另一组对象与历史比较参数（equals或less，阈值2–5）。完整条件组合未用于开发；仍来自同一有界结构族，不是任意未知机制。

## M55：不是预列完整答案

初始模型只有命令乘常数。表达原语由公开字段、整数、模差、相等、小于和条件组合形成；叶值从真实命令/位移推导，树结构由数据递归建造，最大深度3、候选宽度6。没有24张完整动力表或完整目标模型列表。语法、有限深度、候选剪枝和采样规则由研究者提供，不宣称它们也被自主创造。

记录同一实际命令却产生不同效果的两组原始证据，拒绝旧命令唯一解释。Queen依候选分歧选择下一状态，必要时复做旧条件检查适用性。提出条件后，由模型本身选择一次只改变另一位置、对象或先前动作的对照，再改变命令，检查提出的区分。候选固定后另外12次新观测验证；首个反例追加并重新拟合，不能覆盖旧预测。

当前作用程序由生成树编译成函数，实际decide以此搜索可用命令；模型或支持失效后禁止任务执行。历史引用不是证明依赖。证据撤回使依赖许可失效，未依赖它的标定知识保留。范围外/不一致时可拒绝，不能算任务成功。

## M56：迁移、对照和历史干预

模型选择与主动探测只允许目标位置0、2、4、6。每个平稳段结束后，独立评估全部294个目标位置为1、3、5的状态组合；使用同一个Queen的实际绑定程序及实际发令函数，复制物理世界并提供规定的历史上下文，不将结果反馈给学习器。它是绑定程序的只读未来检验，不冒称294项都成为主世界连续亲历。相关物理参数、得分只留在评估层。记录在新物理机制中仍然适用的旧能力是否损失。

主方案、同信息JSON、同表达能力固定取证、2048字节上限的查表、屏蔽当前原始历史、禁止结构扩展六法，使用相同任务和故障序列。树/表均受2048字节部署限制；查表在未记录的完整状态上不臆造值。表达能力不同的负对照不能替代固定取证强基线。

每次修订上限180个探测请求、5000记录读取、5000000读取字节、12000000定义的候选/比较运算。一个Worker标定请求包含两标量，一次准备含一个真实历史引导动作及两次位置夹具设置；全部物理成本另记。记录实际所有read调用、字节、候选比较和运行耗时；ops不是每条Python指令，不能把代理计数当总CPU加速。

每批前两个主轨迹在主实验结束后仍保持同一对象：丢失派生程序，从真实原始历史重建；随后撤回当前区间的作用证据，再丢失派生程序重新取证。物理机制保持不变，比较探测数和迁移。顺序固定而非随机交叉，期间错误与成本另记，不能混进主成绩。所有主/JSON轨迹另外撤回一项实际支持，验证任务阻止及重新取证恢复。

历史归属使用本Queen真实旧意向/后果，与另一控制端在匹配初态实际执行的匿名前后观察。真作者仅在评估器；相同行为保持各1/2，不同效果可区分。提供待回访的自身意向线索、可信自身日志保管、两个候选恰有一个来自自身是明确前提，不是全无线索身份发现。归属与功能分开，元数据和候选顺序不可成为答案。

## M57：两批门槛与总审查

A：22000–22007；B：23000–23007，各8条主轨迹、六法配对。整轨迹为独立单位；不是将大量相关动作当独立自然样本。正式结果不用于修改下一批规则。两批分别必须满足：

1. 每条主轨迹同一实例/账本、原始前缀保持、至少3次启动后实际语义或组件修订，至少1次真正的条件结构改变；初次建模另计。
2. 每条出现同命令冲突的原始证据和自主选择的单变量对照；实际程序仅从原始观察产生，无条件标签/成败反馈输入。可见原因中Worker和自身分别修订，健康组件误改为0。
3. 主方案未用于选择的状态总成功率≥98%，每条轨迹每个平稳段≥95%；旧物理能力仍适用的检验项退化为0。所有预算违例为0。主/JSON逐轨迹一致；不要求主方案击败固定取证。前两条历史重建实验都有实际旧证据使用、两种重建均≥98%迁移且保留历史时探测更少。
4. 可区分归属全部正确，对称归属全部各半，错误确定归属为0，置换等变；每条主轨迹支持撤回使许可失效、任务不执行、其他标定依据保留、重新取证恢复。

只有两批及接口/生命周期回归均满足才报告本有限联合里程碑；否则分级报告检测或局部适应。范围外如位置5且历史6时出现额外位移，只作压力，不反向调主结果。

收尾扫描Library所有可见分支目录与可获取文本/源码，报告实际覆盖和未取到内容；不把目录扫描冒充全历史主实验复跑。编写M0至最终M的总MD，区分并行版本、冻结协议、结果、反例、修补适用入口、遗留档案缺口。所有旧结果和不成立的强主张保留。
