# M5：变化中的历史适用性

状态：已声明变化范围下的操作性证据迁移完成，不涉及哲学身份。

从旧兼容集出发，只释放可能改变的参数槽位，保留其余联合约束。既不清空全部经验，也不机械继承旧答案。定理保证依赖一个重要前提：声明范围覆盖真实变化。

全部 256 初始世界分别测试三种非零 Worker 参数改变，以及三种非零环境参数改变，共 1536 个事件。Worker 改变的 768 个案例中，迁移后全部两次重新识别校正，完全重来则为四次；盲用旧校正全部错误，门禁全部拒绝。

环境改变的 768 个案例中，内部校正目标不变，迁移后零次重新识别即可保留正确校正；完全重来仍要四次。零次仅指重新确定该校正，不包含检测环境事件、验证或监测的成本。

变化范围由实验提供，不是算法从失败中猜出来的。未知结构变化、错误版本声明与跨长期多轮漂移尚未解决。被保留的是证据适用关系，不是宣称 Queen 已经认识到过去与现在都是同一个自我。
