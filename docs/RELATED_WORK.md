# 相关工作与原创性边界

核对日期：2026-09-10。本轮只进行了有限的原始论文摘要核对，不是系统综述、查新报告或「没有人做过」的证明。未读取其他 GitHub 仓库，也未复制外部实现。

## 已有交集

**经验回放。** Schaul、Quan、Antonoglou 与 Silver 的 *Prioritized Experience Replay* 已研究保存并重新使用过去经验，以及优先回放重要经验。因此「可以重新读历史」「选择值得复查的事件」本身不能被我们称为原创。来源：作者论文摘要，arXiv:1511.05952（2015；ICLR 2016）。

<https://arxiv.org/abs/1511.05952>

**自建模与受损后的适应。** Bongard、Zykov 与 Lipson 的 *Resilient Machines Through Continuous Self-Modeling* 描述机器人根据动作—感知关系推断自身结构，并在身体损坏后调整自模型及步态。因此「发现自身问题并调整」不是新的总方向。来源：原论文摘要的 PubMed 记录，*Science* 314(5802), 1118–1121（2006），DOI:10.1126/science.1133687。

<https://pubmed.ncbi.nlm.nih.gov/17110570/>

## 本仓库怎样使用这些资料？

用它们划清重叠，不用它们替代用户提出的图书馆问题。M0 的条件命题从假设直接推导；两两不可区分、四格差分和有向无环证明都是基础推理，不申请为新数学。

「再观察差异」「不足对象」「再观察对照方格」是本地工作术语，不意味着学界不存在同义概念。候选研究贡献是：将比较条件、竞争解释、缺失检验和跨版本适用性组织成 Queen 可继续操作的证据对象，并测量这个组合是否产生独立价值。

下一步不能只证明它会工作，还要在同信息、同预算条件下比较完整回放、自模型等替代机制。没有这种比较，最多可以说构造清晰、原型可运行，不能说原创机制优于既有理论。
